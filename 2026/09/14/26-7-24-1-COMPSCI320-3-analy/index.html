Computational Tractability

Models of Computation: Turing Machines

Finite state machine with infinite tape.

  • Running time: Number fo steps.
  • Memory. Number of tape cells utilized.

Caveat. No random access of memory.

  • Single-Tape TM requires \(\leq n^2\) steps to detect \(n\)-bit palindromes(回文).
  • Easy to detect palindromes in \(\leq cn\) steps on a real computer.

Models of Computation: Word RAM(Random Access Machine)

Word RAM.

  • Each memory location and input/output cell stores a \(w\)-bit integer. \(w \leq \log_2n\).
  • Primitive Operations: arithmetic/logic operations, read/write memory, array indexing, following a pointer, conditional branch, …

Running time. Number of primitive operations.

Memory. Numbers of memory cells utilized.

Caveat. At times, need more refined model (e.g., multiplying \(n\)-bit integers).

Brute Force

For many nontrivial problems, there is a natural brute-force
search algorithm that checks every possible solution.

  • Typically takes \(2^n\) steps (or worse) for inputs of size \(n\).
  • Unacceptable in practice.

Polynomial Running Time

Desirable scaling property. When the input size doubles, the algorithm should slow down by at most some constant factor \(C\).

Complexity \(n \to 2n\) Slow down
\(n\) \(2n\) 2
\(n^3\) \((2n)^3 = 8n^3\) 8
\(2^n\) \(2^{2n} = {2^n}^2\) \(2^n\)(not polynomial)
Poly-Time
An algorithm is poly-time if when the input size doubles, the algorithm should slow down by at most some constant factor \(C\).

We say that an algorithm is efficient if it has a polynomial running time.

Worst-case analysis

Running time guarantee for any input of size \(n\).

  • Generally captures efficiency in practice.
  • Draconian(严格的) view, but hard to find effective alternative.

Some exponential-time algorithms are used widely in practice because the worst-case instances don’t arise.

Other Types of Analyses

Probabilistic. Expected running time of a randomized algorithm.

Amortized. Worst-case running time for any sequence of \(n\) operations.

Also. Average-case analysis, smoothed analysis, competitive analysis, …

Asymptotic Order of Growth

Big O Notation

Upper Bounds
\(f(n)\) is \(O(g(n))\) if there exist constants \(c > 0\) and \(n_0 \geq 0\) such that \(0 \leq f(n) \leq c \cdot g(n)\) for all \(n \geq n_0\).

Typical usage. Insertion sort makes \(O(n^2)\) compares to sort \(n\) elements.

Big O Notational Abuses

\(O(n)\) is a set of functions, but CS directly use \(f(n) = O(g(n))\).

\(g_1(n) = O(n^3)\) and \(g_2(n) = O(n^3)\) don’t mean \(g_1(n) = g_2(n)\).

Domain and Codomain. \(f\) and \(g\) are real-valued functions.

  • The domain is natural numbers \(\mathbb{N} \to \mathbb{R}\).
  • Sometimes we extend to the reals. \(\mathbb{R}_{\leq 0} \to \mathbb{R}\).
  • Or restrict to a subset.

Big O Notation: Properties

Reflexivity. \(f = O(f)\).

Constants. If \(f = O(g), c > 0\), then \(cf = O(g)\).

Products. If \(f_1 = O(g_1), f_2 = O(g_2)\), then \(f_1f_2 = O(g_1g_2)\).

By definition, there are:

  • \(\exists c_1 > 0, n_1 \geq 0\) that \(0 \leq f_1(n) \leq c_1g_1(n)\) for all \(n \geq n_1\).
  • \(\exists c_2 > 0, n_2 \geq 0\) that \(0 \leq f_2(n) \leq c_2g_2(n)\) for all \(n \geq n_2\).
  • Then \(0 \leq f_1(n)f_2(n) \leq c_1c_2g_1(n)g_2(n)\) for all \(n \geq \max\{n_1, n_2\}\).

Sums. If \(f_1 = O(g_1), f_2 = O(g_2)\), then \(f_1 + f_2 = O(\max\{g_1, g_2\})\).

Transitivity. If \(f = O(g), g = O(h)\) then \(f = O(h)\).

Big Omega Notation

Lower Bounds
\(f(n)\) is \(Ω(g(n))\) if there exist constants \(c > 0\) and \(n_0 \geq 0\) such that \(f(n) \geq c \cdot g(n) \geq 0\) for all \(n \geq n_0\).

Big Theta Notation

Tight bounds
\(f(n)\) is \(Θ(g(n))\) if there exist constants \(c1 > 0\), \(c2 > 0\), and \(n_0 \geq 0\) such that \(0 \leq c_1 · g(n) \leq f(n) \leq c_2 · g(n)\) for all \(n \geq n_0\).

Asymptotic Bounds and Limits

If \(\lim_{n \to \infty}\frac{f(n)}{g(n)} = c, 0 < c < \infty\), then \(f(n) = \Theta(g(n))\).

If \(\lim_{n \to \infty}\frac{f(n)}{g(n)} = 0\), then \(f(n) = O(g(n))\).

If \(\lim_{n \to \infty}\frac{f(n)}{g(n)} = \infty\), then \(f(n) = \Omega(g(n))\).

Asymptotic Bounds for Some Common Functions

Polynomials. Let \(f(n) = a_0 + a_1n + \ldots + a_dn^d, a_d > 0\), then \(f(n) = O(n^d)\).

Logarithms. \(\log_an = \Theta(\log_bn)\) for every \(a > 1, b > 1\).

Logarithms and Polynomials. \(\log_an = O(n^d)\) for every \(a > 1, d > 0\).

Exponentials and Polynomials. \(n^d = O(r^n)\) for every \(r > 1, d > 0\).

Factorials. \(n! = 2^{\Theta(n \log n)}\).

Stirling’s Formula
\(n! \sim \sqrt{2 \pi n}(\frac{n}{e})^n\)

Big O Notation with Multiple vVariables

Upper bounds
\(f(m, n)\) is \(O(g(m, n))\) if there exist constants \(c > 0\), \(m_0 \geq 0\), and \(n_0 \geq 0\) such that \(f(m, n) \leq c · g (m, n)\) for all \(n \geq n_0\) and \(m \geq m_0\).

Survey of Common Running Times

Constant Time

Constant Time
Running time is \(O(1)\).

Linear Time

Linear Time
Running time is \(O(n)\).

Merge two sorted lists using mergesort.

Logarithmic Time

Logarithmic Time
Running time is \(O(\log n)\).

Search in a sorted array using binary search.

Linearithmic Time

Linearithmic Time
Running time is \(O(n \log n)\).

Sort an unorded array using mergesort.

Quadratic Time

Quadratic Time
Running time is \(O(n^2)\).

Giving a list of \(n\) points: \((x_1, y_1), (x_2, y_2), \ldots, (x_n, y_n)\), find the closest pair.

Cubic Time

Cubic Time
Running time is \(O(n^3)\).

Given an array of \(n\) distinct integers, find three that sum to 0.

Polynomial Time

Polynomial Time
Running time is \(O(n^k)\) for \(k > 0\).

Given a graph, find \(k\) nodes such that no two are joined by an edge.

Exponential Time

Exponential Time
Running time is \(O(2^{n^k})\) for \(k > 0\).

Given a graph, find independent set of max cardinality.
