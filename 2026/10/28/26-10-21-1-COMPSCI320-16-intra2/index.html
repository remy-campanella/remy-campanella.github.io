【COMPSCI 320】 Lecture 16 Intractability 2

发表于2026-10-28|更新于2026-10-28|技术学习COMPSCI 320 Applied Algorithms

Revision Focus

The 2022 final requires a full NP-completeness proof; 2023 tests class recognition; 2025 Q5 tests the strongest conclusion justified by reduction direction and resource bounds. Prioritize definitions, certificate size, and logical implications. Cook-Levin’s full proof and large gadget details are second-pass material.

P, NP, and EXP

Decision Problems and Input Length

A decision problem is a language \(X\) of encoded instances. A deterministic algorithm decides \(X\) if it halts on every instance and answers yes exactly for strings in \(X\).

\(P\) contains decision problems decidable in polynomial time in \(|x|\). Input length matters: a binary integer of value \(W\) occupies \(\Theta(\log W)\) bits.

Certificates and NP

\(X\in NP\) iff there is a polynomial-time verifier \(C\) and polynomial \(p\) such that \[ x\in X\iff\exists y,\ |y|\leq p(|x|)\text{ and }C(x,y)=\mathrm{yes}. \]

Both polynomial certificate length and polynomial verification time are required. The verifier must reject every certificate for a no-instance. It need not efficiently find a certificate for a yes-instance.

Problem Yes-certificate What to verify
SAT / 3-SAT Truth assignment Every clause has a true literal
CLIQUE \(k\) distinct vertices Every selected pair is adjacent
Hamilton path Ordered list of all vertices No repetition, all vertices present, consecutive pairs are edges
Subset Sum Selected item indices Valid distinct indices and exact target sum
3-COLOR Colour per vertex Every edge has different endpoint colours

The total verification time must include reading the input and checking all required conditions. A Hamilton-path certificate can be checked in polynomial time even though finding one is not known to be polynomial-time.

Inclusions

\[ P\subseteq NP\subseteq EXP, \] where \(EXP=\bigcup_{k\geq1}DTIME(2^{n^k})\).

\(P\subseteq NP\). Use an empty certificate and run the polynomial-time decision algorithm.

\(NP\subseteq EXP\). Enumerate all certificates of polynomial length and run the verifier on each. There are at most exponentially many in a polynomial of the input length.

The question \(P=NP\) asks whether every efficiently verifiable decision problem is efficiently decidable. “NP” means nondeterministic polynomial time, not “not polynomial.” NP-completeness does not by itself prove an exponential lower bound.

NP-Hard and NP-Complete

Use polynomial-time Karp many-one reductions in the standard definitions below.

  • \(Y\) is NP-hard if every \(X\in NP\) reduces to \(Y\).
  • \(Y\) is NP-complete if it is NP-hard and \(Y\in NP\).

An NP-hard problem need not be in NP, or even be a decidable decision problem when hardness is applied more broadly. Optimization versions can be NP-hard; call a problem NP-complete only after specifying its decision version and membership.

A Proof Template

To prove \(Y\) NP-complete:

  1. Give a polynomial-size yes-certificate and polynomial verifier for \(Y\).
  2. Choose an established NP-complete problem \(X\).
  3. Construct \(f(x)\) in polynomial time.
  4. Prove \(x\in X\iff f(x)\in Y\).

Why this works. Every NP problem reduces to \(X\); composition with \(X\leq_PY\) proves \(Y\) NP-hard. Step 1 supplies the separate NP membership.

If an NP-complete problem belongs to \(P\), then \(P=NP\). Conversely, if \(P=NP\), every NP-complete decision problem has a polynomial-time algorithm.

Cook and Karp Reductions

A Cook reduction may query an oracle polynomially many times. A Karp reduction computes one instance preserving yes/no membership. Every polynomial Karp reduction is a polynomial Cook reduction; the reverse is not automatic.

Use the specified notion in each question. In particular, “a polynomial oracle algorithm for \(X\) using \(Y\)” is not itself a many-one transformation unless the single-instance condition is shown.

The First NP-Complete Problems

SAT is NP-complete by Cook-Levin. Circuit satisfiability and 3-SAT are also NP-complete. Recognize the statements and their role as starting points for reductions. The full computation-to-formula proof is lower priority than constructing and verifying a simple new reduction.

Exam Transfer: What Does A Reduce to B Imply? (2025 Q5)

Assume the reduction is Karp many-one as stated in the paper.

Given information about \(A\) and the reduction Justified conclusion about \(B\)
\(A\in P\); polynomial reduction No general upper bound or hardness conclusion about \(B\)
\(A\) NP-complete; polynomial reduction \(B\) is NP-hard; NP membership is still unproved
\(A\) NP-complete; logarithmic-space reduction \(B\) is NP-hard, since a total standard deterministic logspace many-one transformation runs in polynomial time
\(A\) NP-complete; exponential-time reduction No polynomial NP-hardness conclusion follows from that reduction alone
\(A\in NP\); polynomial reduction Does not imply \(B\in NP\) or that \(B\) is NP-hard

For an exponential reduction, the target instance may be exponentially long; a polynomial algorithm for \(B\) would then yield only an exponential procedure through this reduction. If a separate polynomial reduction exists, hardness may still hold, but it has not been proved by the given one.

Direction check. To infer an upper bound for \(B\) from an easy \(A\), the useful direction is \(B\leq_PA\), not \(A\leq_PB\).

Applications and Variants

Longest Path

The decision version asks whether a simple path of at least \(k\) edges exists. Hamilton path reduces to it by setting \(k=n-1\); no simple path on \(n\) vertices has more edges. This proves NP-hardness, and a vertex sequence supplies an NP certificate.

Shortest Path versus Shortest Simple Path

Ordinary unweighted shortest path is polynomial-time by BFS. Nonnegative weighted shortest path is polynomial-time by Dijkstra. Bellman-Ford handles negative edges and detects relevant negative cycles for the unrestricted-walk problem.

If paths are required to be simple and arbitrary negative weights are permitted, the problem changes. Given a Hamilton-path instance, give every edge weight \(-1\) and ask whether some simple path, with unrestricted endpoints, has cost at most \(-(n-1)\). Such a path exists iff there is a Hamilton path. With fixed endpoints, use the corresponding fixed-endpoint Hamilton-path problem or add endpoint gadgets explicitly.

Thus the original claim “Hamilton Path reduces to Shortest Path” requires these restrictions; it is false as an NP-hardness argument for ordinary nonnegative shortest path.

Travelling Salesperson

The decision version asks for a tour of cost at most \(D\). For an undirected Hamilton-cycle instance on \(n\geq3\) vertices, build the complete graph with cost one for original edges and two for missing edges, and set \(D=n\).

A Hamilton cycle gives a cost-\(n\) tour. Conversely, a tour of cost at most \(n\) uses only cost-one edges, hence is a Hamilton cycle in the original graph. The costs satisfy the triangle inequality because each direct edge costs at most two and any two-edge route costs at least two. A tour is a polynomial certificate.

Scheduling with Release Times

A job has processing time \(t_i\), release \(r_i\), and deadline \(d_i\). Ask whether each job can be run nonpreemptively in one contiguous slot on a single machine inside its allowed window.

For Subset Sum weights totalling \(S\) and target \(0<W<S\), make an item job of duration \(w_i\) with window \([0,S+1]\). Add one forced job of duration one with release \(W\) and deadline \(W+1\). Item jobs must fill the intervals before and after that forced slot exactly. Thus the jobs placed before it sum to \(W\), and a subset summing to \(W\) gives a feasible schedule. Targets outside this range and boundary cases can be handled directly.

The binary-encoded job data and construction have polynomial size. Preemption would allow splitting item jobs and invalidate the argument.

Partition

PARTITION asks whether integers can be split into two equal-sum sets. Given a Subset Sum instance with total \(S\) and target \(0\leq W\leq S\), add the number \(|S-2W|\) (omit it if zero).

If \(S\geq2W\), the new half-sum is \(S-W\); a target-\(W\) subset can be joined with the added number, and any equal partition yields either such a subset or its complement. If \(S<2W\), the new half-sum is \(W\) and the same complement argument applies. Hence the answers coincide. This shows why tracking the target and both directions matters.

Planar Colouring

For simple planar graphs, 2-colourability is tested by bipartiteness in linear time; 3-colourability is NP-complete. Under the promise that the input is planar, the decision problem for four colours always answers yes by the four-colour theorem. That does not mean constructing and outputting a colouring takes \(O(1)\) time, or that testing planarity is free when it is not promised.

The planar 3-COLOR crossing gadget is a second-pass construction. Increasing the allowed number of colours does not necessarily preserve hardness.

co-NP and Good Characterizations

For a language \(X\), its complement \(\overline X\) reverses yes and no answers. Define \[ coNP=\{X:\overline X\in NP\}. \]

UNSAT has efficiently checkable no evidence in the form of a satisfying assignment, so it belongs to co-NP. This does not supply a short yes-certificate for unsatisfiability.

\[ P\subseteq NP\cap coNP. \] If both a problem and its complement have polynomial yes-certificates, the problem has a good characterization, but this alone does not give a polynomial-time decision algorithm. Whether \(NP=coNP\) is unresolved; \(P=NP\) would imply equality. The existence of an NP-complete problem in co-NP would also imply \(NP=coNP\) under standard many-one reductions.

Examples

  • Linear programming: rational LP feasibility is in \(P\); primal/dual certificates illustrate short positive and negative evidence.
  • Primality: in \(P\), hence in \(NP\cap coNP\). A nontrivial divisor certifies compositeness.
  • Factoring decision: “does \(x\) have a nontrivial factor less than \(y\)?” is in \(NP\cap coNP\). A small factor certifies yes. For no, a complete prime factorization, with prime certificates if needed, shows every prime factor is at least \(y\).

Factoring search and this decision version are polynomial-time oracle equivalent: binary search locates a factor, divide it out, and repeat. This is an oracle/search reduction, not a reason to label the search problem an NP-complete decision language.

NP-Intermediate and Harder Problems

Ladner’s theorem states that if \(P\ne NP\), some problems in NP are neither in P nor NP-complete. Do not equate “no known polynomial algorithm” with “proved NP-complete.”

PSPACE and undecidability address additional complexity beyond these examples. The course’s quantum-factoring discussion is a separate computation model: Shor’s algorithm gives quantum polynomial-time factoring, not a classical proof that \(P=NP\). Detailed quantum implementation is lower revision priority here.

Final Revision Checklist

  • Distinguish decision, search, and optimization versions.
  • Include certificate length, verifier correctness, and verifier time.
  • Draw the reduction arrow before starting a hardness proof.
  • Bound the encoding size; a large integer can still have few bits.
  • State an iff and prove both directions.
  • Do not infer \(B\in NP\) merely because an NP problem reduces to it.
  • Treat the 2022-2024 format and the six-question 2025 format as historical evidence, not the next exam’s confirmed structure.
