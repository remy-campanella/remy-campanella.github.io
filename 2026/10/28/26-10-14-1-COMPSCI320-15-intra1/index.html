【COMPSCI 320】 Lecture 15 Intractability 1

Revision Focus

The 2022 SAQ4 requires a complete NP-completeness proof for CLIQUE, and SAQ6 asks for a reduction between matching and edge cover. The 2025 Q5 tests what may be concluded from \(A\leq B\) under different resource bounds.

Prioritize reduction direction, polynomial construction size, and both directions of the correctness equivalence. Large Hamilton-cycle, colouring, and numerical gadgets are second-pass details; understanding the proof template remains essential.

Polynomial-Time Reductions

Computational Requirements

An algorithm is polynomial-time if its running time is polynomial in the encoded input length. Numerical magnitudes are not their binary lengths. NP does not mean non-polynomial, and membership in NP alone is not evidence of intractability.

Distinguish solving a decision problem from verifying a proposed yes-certificate. PSPACE and undecidability describe different issues; a problem can be decidable yet have no known polynomial algorithm.

Cook and Karp Reductions

A Cook reduction solves \(X\) using polynomial ordinary work and polynomially many oracle calls to \(Y\), on polynomial-size queries.

A Karp many-one reduction computes a polynomial-time function \(f\) such that \[ x\in X\iff f(x)\in Y. \] It uses one transformed decision instance and preserves yes/no answers. Use this convention for the NP-hardness constructions below and for 2025 Q5. Do not silently replace a many-one requirement by a multi-query oracle algorithm.

What the Arrow Means

\(X\leq_PY\) means an algorithm for \(Y\) can solve \(X\), after the permitted transformation.

  • If \(Y\in P\), then \(X\in P\).
  • If \(X\) is NP-hard, then \(Y\) is NP-hard.
  • If \(X\notin P\), then \(Y\notin P\).
  • If \(X\in P\), no upper bound on \(Y\) follows.
  • For many-one reductions, \(Y\in NP\) implies \(X\in NP\); \(X\in NP\) does not imply \(Y\in NP\).

Reductions compose. To prove a new problem \(Y\) hard, reduce a known hard problem to \(Y\), not the other way around.

A Complete Reduction Answer

  1. Name the source problem and define its input.
  2. Construct the target instance, including its parameter.
  3. Bound construction time and output size polynomially.
  4. Prove source yes \(\Rightarrow\) target yes.
  5. Prove target yes \(\Rightarrow\) source yes.
  6. For NP-completeness, separately prove that the target has polynomial-size yes-certificates and a polynomial-time verifier.

Packing and Covering Problems

Independent Set and Vertex Cover

An independent set \(I\) contains no adjacent vertices. A vertex cover \(C\) touches every edge.

Lemma. \(I\) is independent iff \(V\setminus I\) is a vertex cover.

Proof. If an edge were uncovered by \(V\setminus I\), both its endpoints would lie in \(I\), contradicting independence. Conversely, an edge inside \(I\) would be uncovered by its complement.

Thus \[ (G,k)\in\mathrm{IS}\iff(G,|V|-k)\in\mathrm{VC}, \] using “at least \(k\)” for IS and “at most \(|V|-k\)” for VC. The same complement operation gives the reverse reduction.

CLIQUE via the Complement Graph (2022 SAQ4)

A clique of size at least \(k\) is a vertex set with all pairs adjacent. For the complement graph \(\overline G\), distinct vertices are adjacent exactly when they are not adjacent in \(G\). \[ G\text{ has an independent set of size at least }k \iff\overline G\text{ has a clique of size at least }k. \]

Construction. Build the complement in \(O(n^2)\) time and keep \(k\) unchanged.

Both directions. Every non-edge between selected vertices in \(G\) is an edge in \(\overline G\), and conversely. Thus IS reduces to CLIQUE and proves NP-hardness.

Membership in NP. A certificate lists \(k\) distinct vertices; verify their validity and all \(\binom{k}{2}\) edges. With an adjacency matrix this costs \(O(k^2)\) after graph preparation. Therefore CLIQUE is NP-complete. A verifier is not a polynomial-time search algorithm for the clique.

Set Cover

Given universe \(U\), subsets \(S_1,\ldots,S_m\), and budget \(k\), ask whether at most \(k\) subsets cover every element.

Vertex Cover \(\leq_P\) Set Cover. Let \(U=E\) and create \(S_v=\{e:e\text{ is incident to }v\}\) for every vertex. Keep budget \(k\). Selected vertices cover all edges iff their corresponding subsets cover \(U\). Total incidence size is \(2|E|\), so the construction is polynomial.

Constraint Satisfaction

SAT and 3-SAT

A literal is a variable or its negation. A clause is a disjunction of literals. CNF is a conjunction of clauses. SAT asks for a satisfying assignment; 3-SAT restricts clauses to three literals in the course formulation.

The number of clauses and the total encoded formula size are different parameters; state which one is used.

3-SAT Reduces to Independent Set

Given \(m\) clauses, make a vertex for each literal occurrence.

  • Join the three occurrence vertices of each clause into a triangle.
  • Join occurrences in different clauses whenever their literals are complementary.
  • Ask for an independent set of size \(m\).

Forward. From a satisfying assignment, choose one true occurrence per clause. No two chosen occurrences are in the same triangle or are complementary, so they form an independent set of size \(m\).

Reverse. Each triangle contributes at most one vertex, so a size-\(m\) independent set contains one occurrence per clause. No selected literals contradict each other. Assign their variables accordingly and fill other variables arbitrarily; every clause has a selected true literal.

There are \(3m\) vertices and at most \(O(m^2)\) edges. Repeated variables require occurrence vertices, not one vertex per variable.

Sequencing Problems

Hamilton Cycle

A Hamilton cycle visits every vertex exactly once before returning to its start. Hamilton path has no closing requirement. Directed versions must follow arc directions. These ask for vertex visits; Euler problems ask for edge visits.

Directed Hamilton Cycle to Undirected Hamilton Cycle

Replace each directed vertex \(v\) by a path \(v_{in}-v_{mid}-v_{out}\). For each original arc \(u\to v\), add the undirected edge \(u_{out}v_{in}\).

The middle vertex has degree two, forcing every Hamilton cycle to traverse its entire three-vertex gadget. After orienting the whole cycle, traversals consistently run from in to out, and inter-gadget edges correspond to directed arcs. Contracting gadgets recovers a directed Hamilton cycle; expanding a directed cycle gives an undirected one. The construction has \(3|V|\) vertices and \(2|V|+|E|\) edges. Small degenerate input cases can be handled separately.

3-SAT to Directed Hamilton Cycle

The lecture uses variable paths that can be traversed in two directions for truth values, and clause vertices that can be visited through a detour only through an appropriate literal choice. A satisfying assignment permits all clause detours; a Hamilton cycle’s traversals encode consistent truth choices satisfying all clauses.

Revision depth. Recognize the role of variable choice, clause satisfaction, and the reverse implication. This paragraph is an overview, not a complete gadget construction suitable to submit as a proof. Reproduce the full lecture construction if specifically asked; prioritize the complete IS/CLIQUE reduction above first.

Partitioning and Colouring

Three-Dimensional Matching

Given disjoint \(X,Y,Z\), each of size \(n\), and allowed triples \(T\subseteq X\times Y\times Z\), ask whether \(n\) triples cover every element exactly once. This is not ordinary bipartite matching; moving from two sets to triples changes the problem’s complexity.

3-Colourability

Assign one of three colours to each vertex so adjacent vertices differ. In the SAT reduction, a fixed reference triangle establishes three colour roles, variable gadgets enforce opposite truth colours for a variable and its negation, and clause gadgets enforce satisfaction.

As with Hamilton-cycle gadgets, knowing the gadget’s intended function does not replace proving that it has exactly the required valid extensions. The full construction is a second-pass task; the ability to verify a colouring certificate and explain the reduction direction is first-pass material.

Numerical Problems

Subset Sum

Given nonnegative integers \(w_1,\ldots,w_n\) and target \(W\), ask whether a subset sums exactly to \(W\). A DP over targets takes \(O(nW)\) time, which is pseudo-polynomial in the binary encoding.

3-SAT to Subset Sum: Construction Principle

Use positional digits with one column per variable and per clause. For each variable, create a true-choice and false-choice number, both carrying one in that variable column and contributions to satisfied clauses. Target one in each variable column forces exactly one truth choice. Clause slack numbers allow a clause target to be met iff at least one chosen literal satisfies it.

The base must prevent carry between columns, and the numbers’ bit lengths must be polynomial. Large numerical values alone do not make a reduction exponential. For revision, understand the choice/slack/no-carry roles; a full numerical gadget proof needs its exact digits and both implications.

Subset Sum Reduces to 0-1 Knapsack

The knapsack decision version asks for a subset \(S\) satisfying \[ \sum_{i\in S}u_i\leq U,\qquad\sum_{i\in S}v_i\geq V, \] with positive weights and nonnegative values. Set \(u_i=v_i=w_i\) and \(U=V=W\). The two inequalities force the same sum to equal \(W\), proving equivalence. The value condition is at least, not at most.

Exam Transfer: Matching and Minimum Edge Cover (2022 SAQ6)

For an undirected graph with no isolated vertices, let \(\nu\) be its maximum matching size and \(\rho\) its minimum edge-cover size. An edge cover touches every vertex, unlike a vertex cover, which touches every edge. \[ \rho=|V|-\nu. \]

From a maximum matching, add one incident edge for each unmatched vertex. No two unmatched vertices are adjacent, or the matching could be enlarged, so this gives an edge cover with \(\nu+(|V|-2\nu)=|V|-\nu\) edges.

Conversely, take a minimum edge cover and delete any redundant edges. Each component is a star: an edge whose endpoints both have degree at least two would be redundant. If the cover has \(c\) components, it has \(|V|-c\) edges, and choosing one edge per component gives a matching of size \(c\leq\nu\). Therefore \(\rho\geq|V|-\nu\).

Compute a maximum matching and extend it as above to solve the edge-cover problem in polynomial time. This is an optimization/oracle reduction, consistent with the course’s Cook-reduction setting; distinguish it from a decision many-one construction.
