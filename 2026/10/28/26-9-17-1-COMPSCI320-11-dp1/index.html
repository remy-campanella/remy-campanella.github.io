Revision Focus

The 2022-2024 finals all include DP design questions and test knapsack/alignment in MCQs. The 2025 paper’s omission of DP is not evidence that it is outside the syllabus. Prioritize state meaning, recurrence, boundaries, evaluation order, reconstruction, and complexity. The matrix and stock examples below are derived solutions to past-paper tasks, not official marking schemes.

Dynamic Programming

A Design Template

DP solves overlapping subproblems and stores each answer once. To justify a recurrence, classify an optimal solution by its last decision and show that the remaining parts must also be optimal.

For an exam answer, explicitly give:

  1. The meaning and domain of every state.
  2. The choices and why they exhaust all possible optimal solutions.
  3. Base and impossible states.
  4. A topological evaluation order.
  5. The state containing the final answer and how to recover a solution if requested.
  6. Number of states times work per state, plus preprocessing costs.

Memoization is top-down caching; tabulation is bottom-up evaluation. A recurrence without caching can still be exponential.

Weighted Interval Scheduling

Problem and Binary Choice

Job \(j\) has start \(s_j\), finish \(f_j\), and weight \(w_j\). Find a mutually compatible subset of maximum total weight. Earliest-finish greedy is not generally optimal with unequal weights: one long, high-weight job can outweigh two short jobs.

Sort jobs so that \(f_1\leq\cdots\leq f_n\). Let \[ p(j)=\max\{i<j:f_i\leq s_j\}, \] with \(p(j)=0\) if the set is empty. Let \(M[j]\) be the optimal weight using only the first \(j\) jobs. \[ M[0]=0,\qquad M[j]=\max\{M[j-1],w_j+M[p(j)]\}. \]

Correctness. An optimal subset either omits \(j\), leaving an optimum on the first \(j-1\) jobs, or includes \(j\), leaving an optimum on the compatible prefix ending at \(p(j)\).

Memoization and Dependency Order

A top-down implementation returns \(M[j]\) immediately if it is already cached; otherwise it evaluates the two smaller states, stores their maximum, and returns it. Initialize \(M[0]=0\) and mark all other states unknown. A legitimate optimal value of zero must not be confused with an unknown entry.

Both dependencies, \(j-1\) and \(p(j)\), are smaller than \(j\). Thus a bottom-up pass in increasing \(j\) is valid. There are only \(n+1\) states, even though the uncached recursion tree can have exponentially many calls. Predecessor computation, rather than the recurrence itself, accounts for the \(O(n\log n)\) total bound.

Bottom-Up Implementation

\begin{algorithm}
\caption{Weighted-Interval-Scheduling}
\begin{algorithmic}
\PROCEDURE{Weighted-Interval-Scheduling}{$J$}
    \STATE Sort jobs by finish time and compute all $p(j)$ by binary search
    \STATE $M[0] \gets 0$
    \FOR{$j \gets 1$ \TO $n$}
        \STATE $M[j] \gets \max\{M[j-1], w_j+M[p(j)]\}$
    \ENDFOR
    \RETURN $M[n]$
\ENDPROCEDURE
\end{algorithmic}
\end{algorithm}

Sorting and computing predecessors take \(O(n\log n)\); DP takes \(O(n)\) time and space. A memoized implementation has the same DP cost after preprocessing.

Finding a Solution

Start at \(j=n\). If \(w_j+M[p(j)]>M[j-1]\), select \(j\) and set \(j=p(j)\); otherwise set \(j=j-1\). Either choice is valid on a tie. Reverse the recovered job list if chronological order is needed. Recovery takes \(O(n)\) time.

Maximum Subarray Problem

For a nonempty contiguous subarray, define \(E[j]\) as the maximum sum ending exactly at position \(j\): \[ E[1]=A_1,\qquad E[j]=\max\{A_j,E[j-1]+A_j\}. \] The answer is \(\max_j E[j]\), computed in \(O(n)\) time and \(O(1)\) extra space. Track starting indices to recover the interval. Initializing the answer to zero incorrectly permits an empty subarray when all values are negative.

2024 SAQ4 requires divide and conquer. For an interval split at \(m\), the optimum is entirely left, entirely right, or crosses \(m\). The best crossing sum is the maximum nonempty suffix of the left half plus the maximum nonempty prefix of the right half. Computing these by scans gives \[ T(n)=2T(n/2)+O(n)=O(n\log n). \]

A faster divide-and-conquer variant returns four values per segment: total sum, best prefix, best suffix, and best subarray. For left summary \((S_L,P_L,Q_L,B_L)\) and right summary \((S_R,P_R,Q_R,B_R)\), \[ \begin{aligned} S&=S_L+S_R,&P&=\max\{P_L,S_L+P_R\},\\ Q&=\max\{Q_R,S_R+Q_L\},&B&=\max\{B_L,B_R,Q_L+P_R\}. \end{aligned} \] Constant-time merging gives \(O(n)\) total time. Explain this summary if using the faster variant; giving only Kadane’s algorithm does not satisfy a divide-and-conquer requirement.

Maximum-Sum Rectangle: Bentley’s Algorithm

Course extension (DP1 PDF pp. 21-22). Given an \(m\)-by-\(n\) matrix, find a nonempty axis-aligned submatrix with maximum sum.

Fix left and right columns \(l,r\). For each row, compress the entries between them into \[ x_i=\sum_{j=l}^r A_{ij}. \] Any rectangle with these column boundaries corresponds to a contiguous subarray of \(x\), so Kadane’s algorithm finds its best top and bottom rows in \(O(m)\) time.

Enumerate all \(O(n^2)\) column pairs. Row prefix sums or incrementally accumulated row totals make the total time \(O(mn^2)\), or \(O(n^3)\) for a square matrix. Transpose the roles of rows and columns when useful to obtain \(O(mn\min\{m,n\})\). Keep the best four boundaries to output the rectangle; initialize the best sum to \(-\infty\) for the nonempty convention.

The progression is useful for new exam tasks: brute-force enumeration, prefix-sum improvement, then reduction to a known one-dimensional DP. It is not a claim that the most advanced possible rectangle algorithm must be reproduced in the exam.

Segmented Least Squares

For points with increasing \(x\)-coordinates, let \(e(i,j)\) be the minimum squared error of fitting one line to points \(i,\ldots,j\). Charge a fixed penalty \(C>0\) per segment.

The objective is total squared error plus \(C\) times the number of segments. Define \(M[j]\) as the minimum cost for the first \(j\) points: \[ M[0]=0,\qquad M[j]=\min_{1\leq i\leq j}\{M[i-1]+e(i,j)+C\}. \] The last segment starts at some \(i\), which proves the recurrence. Save the minimizing \(i\) to reconstruct segments by repeatedly moving from \(j\) to \(i-1\).

Computing the Fitting Error

For an interval containing \(q=j-i+1\) points, define \(S_x,S_y,S_{xx},S_{xy},S_{yy}\) as the sums of \(x,y,x^2,xy,y^2\) over that interval. For \(q\geq2\) and distinct \(x\)-coordinates, the best-fit line \(y=ax+b\) has \[ a=\frac{qS_{xy}-S_xS_y}{qS_{xx}-S_x^2},\qquad b=\frac{S_y-aS_x}{q}, \] \[ e(i,j)=S_{yy}-2aS_{xy}-2bS_y+a^2S_{xx}+2abS_x+qb^2. \] A one-point interval has error zero. A direct scan takes \(O(q)\) per interval, so the basic lecture implementation takes \(O(n^3)\) time and \(O(n^2)\) stored-error space. Prefix sums give all five interval sums in \(O(1)\) and improve the total time to \(O(n^2)\); the DP itself already takes only \(O(n^2)\).

\begin{algorithm}
\caption{Segmented-Least-Squares}
\begin{algorithmic}
\PROCEDURE{Segmented-Least-Squares}{$p_1,\ldots,p_n,C$}
    \STATE Compute the least-squares errors $e(i,j)$ for all $1\leq i\leq j\leq n$
    \STATE $M[0]\gets0$
    \FOR{$j\gets1$ \TO $n$}
        \STATE Choose $i$ minimizing $M[i-1]+e(i,j)+C$
        \STATE $M[j]\gets M[i-1]+e(i,j)+C$
        \STATE $start[j]\gets i$
    \ENDFOR
    \RETURN $M[n]$ and the segments recovered using $start$
\ENDPROCEDURE
\end{algorithmic}
\end{algorithm}

This is a useful last-segment DP pattern, with lower revision priority than knapsack and grid DP.

The Knapsack Problem

Fractional and 0-1 Versions

Fractional knapsack allows \(0\leq x_i\leq1\) and admits the value-density greedy rule. In 0-1 knapsack, each item is used at most once: \(x_i\in\{0,1\}\).

Given positive integer weights \(w_i\), values \(v_i\geq0\), and integer capacity \(W\), let \(M[i,w]\) be the maximum value using the first \(i\) items and weight at most \(w\). \[ M[i,w]=\begin{cases} 0,&i=0,\\ M[i-1,w],&w_i>w,\\ \max\{M[i-1,w],v_i+M[i-1,w-w_i]\},&w_i\leq w. \end{cases} \] Answer: \(M[n,W]\). Fill increasing \(i\); each row uses the previous row. Complexity: \(O(nW)\) time and \(O(nW)\) space, or \(O(W)\) space for the value alone.

For a one-dimensional table, process \(w=W,W-1,\ldots,w_i\) for each item. Increasing \(w\) would allow repeated use of the same item and solve an unbounded variant.

Reconstruction. Compare \(M[i,w]\) with \(M[i-1,w]\). A strict improvement selects item \(i\) and decreases \(w\) by \(w_i\); ties may choose either valid optimum. A full table or saved decisions support recovery.

Pseudo-polynomial. \(O(nW)\) is not polynomial in the binary input length when \(W\) may be exponentially large. This does not contradict NP-completeness of the decision version.

Bottom-Up Knapsack Implementation

\begin{algorithm}
\caption{Knapsack}
\begin{algorithmic}
\PROCEDURE{Knapsack}{$w_1,\ldots,w_n,v_1,\ldots,v_n,W$}
    \STATE Set $M[0,w]\gets0$ for every $0\leq w\leq W$
    \FOR{$i\gets1$ \TO $n$}
        \FOR{$w\gets0$ \TO $W$}
            \IF{$w_i>w$}
                \STATE $M[i,w]\gets M[i-1,w]$
            \ELSE
                \STATE $M[i,w]\gets\max\{M[i-1,w],v_i+M[i-1,w-w_i]\}$
            \ENDIF
        \ENDFOR
    \ENDFOR
    \RETURN $M[n,W]$
\ENDPROCEDURE
\end{algorithmic}
\end{algorithm}

The weight domain is integral; the recurrence does not require integer values. The table is for weight at most \(w\), so unused capacity is allowed.

Coin Changing

Given positive integer denominations \(d_1,\ldots,d_n\) with unlimited copies and target \(V\), let \(M[v]\) be the fewest coins making exactly \(v\): \[ M[0]=0,\qquad M[v]=1+\min_{i:d_i\leq v}M[v-d_i]\quad(v>0). \] Take the minimum of an empty set as \(+\infty\). Fill \(v=1,\ldots,V\); \(M[V]=+\infty\) means impossible. Time is \(O(nV)\) and space \(O(V)\). Store the chosen denomination to recover coins. This recurrence allows reuse, unlike 0-1 knapsack.

RNA Secondary Structure

A valid structure is a matching of bases with Watson-Crick complements, at least four intervening bases per pair, and no crossing pairs: pairs \((i,j)\) and \((k,l)\) with \(i<k<j<l\) are forbidden.

Let \(M[i,j]\) be the maximum number of pairs within interval \(i,\ldots,j\). Set \(M[i,j]=0\) for \(i\geq j\) and for intervals too short to pair. Consider whether \(j\) is unmatched or paired with \(t\): \[ M[i,j]=\max\left\{M[i,j-1],\max_{\substack{i\leq t\leq j-5\\b_t,b_j\text{ complementary}}}\{1+M[i,t-1]+M[t+1,j-1]\}\right\}. \] Noncrossing makes the two resulting intervals independent. Fill increasing interval length. There are \(O(n^2)\) states and \(O(n)\) choices per state: \(O(n^3)\) time, \(O(n^2)\) space. Store whether \(j\) is paired and its partner for reconstruction.

Interval-DP Implementation

A prefix-only state cannot describe the interior and exterior pieces created by a base pair. Both interval endpoints are necessary.

\begin{algorithm}
\caption{RNA-Secondary-Structure}
\begin{algorithmic}
\PROCEDURE{RNA-Secondary-Structure}{$b_1,\ldots,b_n$}
    \STATE Set $M[i,j]\gets0$ for empty intervals and intervals with $j-i\leq4$
    \FOR{$k\gets5$ \TO $n-1$}
        \FOR{$i\gets1$ \TO $n-k$}
            \STATE $j\gets i+k$
            \STATE $M[i,j]\gets M[i,j-1]$
            \FOR{$t\gets i$ \TO $j-5$}
                \IF{$b_t$ and $b_j$ are Watson-Crick complements}
                    \STATE $M[i,j]\gets\max\{M[i,j],1+M[i,t-1]+M[t+1,j-1]\}$
                \ENDIF
            \ENDFOR
        \ENDFOR
    \ENDFOR
    \RETURN $M[1,n]$
\ENDPROCEDURE
\end{algorithmic}
\end{algorithm}

Matrix Chain Order

Matrix \(A_i\) has dimensions \(d_{i-1}\times d_i\). Associativity changes the cost, not the resulting matrix. Let \(M[i,j]\) be the fewest scalar multiplications for \(A_i\cdots A_j\). \[ M[i,i]=0,\qquad M[i,j]=\min_{i\leq k<j}\{M[i,k]+M[k+1,j]+d_{i-1}d_kd_j\}. \] The three costs are added, not individually minimized. Fill increasing chain length, save the best split \(k\), and recursively print the two subchains. Time is \(O(n^3)\) and space \(O(n^2)\).

Example: dimensions \((10,30,5,60)\) give \((A_1A_2)A_3\) cost \(1500+3000=4500\), versus \(A_1(A_2A_3)\) cost \(9000+18000=27000\).

Matrix-Chain Implementation and Parentheses

\begin{algorithm}
\caption{Matrix-Chain-Order}
\begin{algorithmic}
\PROCEDURE{Matrix-Chain-Order}{$d_0,\ldots,d_n$}
    \STATE Set $M[i,i]\gets0$ for $1\leq i\leq n$
    \FOR{$h\gets1$ \TO $n-1$}
        \FOR{$i\gets1$ \TO $n-h$}
            \STATE $j\gets i+h$
            \STATE $M[i,j]\gets\infty$
            \FOR{$k\gets i$ \TO $j-1$}
                \STATE $q\gets M[i,k]+M[k+1,j]+d_{i-1}d_kd_j$
                \IF{$q<M[i,j]$}
                    \STATE $M[i,j]\gets q$
                    \STATE $S[i,j]\gets k$
                \ENDIF
            \ENDFOR
        \ENDFOR
    \ENDFOR
    \RETURN $M[1,n]$ and split table $S$
\ENDPROCEDURE
\end{algorithmic}
\end{algorithm}

To print the order for interval \((i,j)\), output \(A_i\) if \(i=j\); otherwise let \(k=S[i,j]\) and output an opening parenthesis, the order for \((i,k)\), the order for \((k+1,j)\), and a closing parenthesis. Recovery takes \(O(n)\) output operations. A split index is stored only when it attains the current minimum; arbitrary split indices need not describe an optimal order.

Exam Transfer: Designing New States

Longest Grid Sequence (2022 SAQ3)

Moves are only right or down, and adjacent values must differ by exactly one. A sequence may start anywhere. Let \(D[i,j]\) be the longest valid sequence starting at cell \((i,j)\): \[ D[i,j]=1+\max\left(\{0\}\cup\{D[u,v]:(u,v)\in\{(i+1,j),(i,j+1)\},\ |A[u,v]-A[i,j]|=1\}\right), \] using only valid cells. Fill bottom-to-top and right-to-left. The answer is \(\max_{i,j}D[i,j]\), not necessarily \(D[1,1]\). Time and table space are \(O(mn)\).

At Most k Stock Transactions (2023 SAQ5)

Let \(P[t,d]\) be the maximum profit using at most \(t\) completed transactions during days \(1,\ldots,d\). Set \(P[0,d]=P[t,0]=0\).

An optimum either does not sell on day \(d\), or buys on day \(b<d\) and sells on \(d\): \[ P[t,d]=\max\left\{P[t,d-1],\ A[d]+\max_{1\leq b<d}\big(P[t-1,b-1]-A[b]\big)\right\}. \] Restricting earlier transactions to day \(b-1\) ensures non-overlap. Same-day zero-profit transactions are unnecessary. A direct implementation takes \(O(kn^2)\) time.

For \(O(kn)\) time, for each \(t\), maintain the inner maximum while scanning \(d\). Before evaluating day \(d\geq2\), insert candidate \(b=d-1\): update \(best=\max\{best,P[t-1,d-2]-A[d-1]\}\). Then set \(P[t,d]=\max\{P[t,d-1],A[d]+best\}\). Set \(P[t,1]=0\) and initially \(best=-\infty\).

The answer is \(P[k,n]\); use two rows for \(O(n)\) value-only space. Save sell/buy decisions if transactions must be output. For \((10,22,5,75,65,80)\) and \(k=2\), the optimum is \(87\).
