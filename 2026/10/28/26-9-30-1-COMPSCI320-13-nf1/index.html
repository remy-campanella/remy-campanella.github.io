【COMPSCI 320】 Lecture 13 Network Flow 1

发表于2026-10-28|更新于2026-10-28|技术学习COMPSCI 320 Applied Algorithms

Revision Focus

Network flow appears in all four finals examined. The 2022 SAQ5 asks for a residual network, a maximum-bottleneck augmenting path, and a flow with an equal-capacity cut. The 2024 SAQ2 asks for a capacity-change proof and counterexample; 2025 Q6(a) again asks for a justified maximum flow.

First master residual edges, augmentation, and the optimality certificate. Then learn matching and vertex splitting in Lecture 14. Advanced running-time proofs are a second-pass topic, not a replacement for modelling practice.

Max-Flow and Min-Cut Problems

Flow Network

A flow network is a directed graph \(G=(V,E)\) with source \(s\), sink \(t\), and nonnegative capacities \(c(e)\geq0\).

A feasible flow satisfies \[ 0\leq f(e)\leq c(e)\quad(e\in E), \] \[ \sum_{e\text{ into }v}f(e)=\sum_{e\text{ out of }v}f(e)\quad(v\notin\{s,t\}). \] Its value is the net flow leaving the source: \[ |f|=\sum_{e\text{ out of }s}f(e)-\sum_{e\text{ into }s}f(e). \] The maximum-flow problem maximizes this value. Flow into the sink is equal to the value by conservation.

Minimum Cut

An \(s\)-\(t\) cut is a partition \((A,B)\) with \(s\in A\) and \(t\in B\). Its capacity is \[ c(A,B)=\sum_{\substack{(u,v)\in E\\u\in A,v\in B}}c(u,v). \] Count only original edges directed from \(A\) to \(B\); do not add edges in the reverse direction.

Residual Networks and Augmentation

Why a Forward-Only Greedy Algorithm Fails

An early path can use capacity needed by a better routing. The algorithm must be able to undo part of that decision. A reverse residual edge represents cancelling existing flow, not creating negative physical flow.

Residual Graph

For each original edge \(e=(u,v)\), create separately identified residual arcs:

Residual arc Capacity Meaning
Forward \(u\to v\) \(c(e)-f(e)\) Send more on \(e\)
Backward \(v\to u\) \(f(e)\) Cancel flow on \(e\)

Only positive-capacity arcs can be used in an augmenting path. If the original network contains antiparallel edges, keep each edge’s residual pair distinct, or aggregate carefully; testing whether an ordered pair is an original edge is not enough to determine its update.

A feasible residual flow can be added to the current flow using \[ f_{\mathrm{new}}(e)=f(e)+g(e_{\mathrm{forward}})-g(e_{\mathrm{backward}}). \] This gives another feasible original flow. This implication does not mean every representation of a feasible flow difference is automatically feasible in the residual graph.

Augmenting Path

An augmenting path is a simple \(s\to t\) path \(P\) of positive residual arcs. Its bottleneck is \[ \Delta=\min_{a\in P}c_f(a). \] Increase each forward original-edge flow by \(\Delta\), and decrease each backward original-edge flow by \(\Delta\).

Why feasible? Residual capacities enforce the original lower/upper bounds. Internal path vertices gain and lose the same amount of net flow. The source gains net outflow \(\Delta\), so \(|f_{\mathrm{new}}|=|f|+\Delta\).

Ford-Fulkerson Algorithm

\begin{algorithm}
\caption{Ford-Fulkerson}
\begin{algorithmic}
\PROCEDURE{Ford-Fulkerson}{$G,s,t,c$}
    \STATE Set $f(e)\gets0$ for every original edge $e$
    \STATE Construct the residual network $G_f$
    \WHILE{there exists an $s$ to $t$ path $P$ in $G_f$}
        \STATE $\Delta\gets\min_{a\in P}c_f(a)$
        \FORALL{residual arcs $a$ on $P$}
            \IF{$a$ is the forward arc of original edge $e$}
                \STATE $f(e)\gets f(e)+\Delta$
            \ELSE
                \STATE $f(e)\gets f(e)-\Delta$ for the original edge $e$ represented by $a$
            \ENDIF
        \ENDFOR
        \STATE Update the residual capacities
    \ENDWHILE
    \RETURN $f$
\ENDPROCEDURE
\end{algorithmic}
\end{algorithm}

With integer capacities, each augmentation raises the integer value by at least one. If the maximum value is \(F\), there are at most \(F\) augmentations, taking \(O((|V|+|E|)F)\) time with a graph search per path. This is pseudo-polynomial in capacity magnitudes. Arbitrary irrational capacities do not guarantee termination for arbitrary path choices.

Max-Flow Min-Cut Theorem

Flow Value Lemma

For every feasible flow and every \(s\)-\(t\) cut, \[ |f|=\sum_{e\text{ out of }A}f(e)-\sum_{e\text{ into }A}f(e). \]

Proof. Sum net outflow over all vertices of \(A\). Internal vertices contribute zero by conservation; only \(s\) contributes \(|f|\). Edges internal to \(A\) cancel, leaving exactly the two boundary sums.

Weak Duality and an Optimality Certificate

Nonnegative flow and capacity constraints give \[ |f|\leq\sum_{e\text{ out of }A}f(e)\leq\sum_{e\text{ out of }A}c(e)=c(A,B). \]

Thus a feasible flow and a cut with equal values certify both optima. Merely giving a plausible large flow is insufficient.

Equivalent Conditions

For any feasible \(f\), the following are equivalent:

  1. Some cut has capacity \(|f|\).
  2. \(f\) is a maximum flow.
  3. There is no residual augmenting path.

Proof. (1)\(\Rightarrow\)(2) follows from weak duality. For (2)\(\Rightarrow\)(3), an augmenting path would strictly improve the flow.

For (3)\(\Rightarrow\)(1), let \(A\) be all vertices reachable from \(s\) by positive residual arcs, and let \(B=V\setminus A\). Then \(s\in A\) and \(t\notin A\) because no augmenting path exists. Every original edge from \(A\) to \(B\) is saturated; otherwise its forward residual arc would reach \(B\). Every original edge from \(B\) to \(A\) has zero flow; otherwise its reverse residual arc would reach \(B\). Therefore \[ |f|=\sum_{e\text{ out of }A}c(e)-0=c(A,B). \]

Consequently, the maximum-flow value equals the minimum-cut capacity. Recovering the reachable set in the final residual graph is also how to output an actual minimum cut.

Faster Path Choices

Capacity Scaling

For integer capacities at most \(U\), start with the largest power of two \(\Delta\leq U\). Use only residual arcs of capacity at least \(\Delta\), augment until no such path exists, and halve \(\Delta\) until it drops below one.

At the end of a phase, the reachable-set argument bounds the remaining possible improvement by \(O(|E|\Delta)\). This yields \(O(|E|)\) augmentations per scale and the standard \(O(|E|^2\log U)\) bound, after discarding irrelevant isolated vertices. Know what changes in the residual search; the full amortized proof is lower priority.

Shortest Augmenting Path: Edmonds-Karp

Use BFS to choose a path with the fewest residual edges, not minimum weight or maximum bottleneck. Residual BFS distances never decrease; an edge can become a critical saturated edge only \(O(|V|)\) times. Thus there are \(O(|V||E|)\) augmentations and \(O(|V||E|^2)\) time.

This bound is independent of numerical capacity magnitudes. It is a different path rule from the largest-bottleneck request in 2022 SAQ5.

Dinitz’s Algorithm

BFS builds a level graph containing only residual arcs from level \(i\) to \(i+1\). Send a blocking flow, eliminating every \(s\to t\) path in this level graph, then rebuild levels. A blocking flow need not be a maximum flow of the whole residual network.

The distance to \(t\) increases between phases. The standard general bound is \(O(|V|^2|E|)\). Specialized networks admit better bounds; focus first on BFS levels, blocking flow, and why a new phase is needed.

Simple Unit-Capacity Networks

Every edge has capacity one, and every internal vertex has exactly one entering edge or exactly one leaving edge (possibly both). These are often called unit networks; they are more restrictive than merely requiring all capacities to be one.

Their structure underlies the \(O(|E|\sqrt{|V|})\) Dinitz bound and the corresponding matching improvement. Do not apply that bound to an arbitrary unit-capacity graph without checking the stronger vertex condition.

Exam Transfer: Changing Capacities (2024 SAQ2)

Let \(P\) be an original simple \(s\to t\) path of \(k\) edges. Increase every capacity on \(P\) by one, and let the old maximum value be \(F\).

At least \(F+1\). Start with an old maximum flow and add one unit along \(P\). Each changed edge has one extra unit of capacity, and conservation holds at every internal path vertex.

Not necessarily exactly \(F+1\). Use edges \(s\to a\to b\to t\), each of capacity one, plus \(s\to b\) and \(a\to t\), each of capacity two. The old cut \(A=\{s,b\}\) has capacity two, matched by one unit on each of \(s\to a\to t\) and \(s\to b\to t\). Thus \(F=2\).

Increasing the three path-edge capacities to two allows two units on each of those two routes, giving value four. The source outgoing capacity is four, so the new optimum is exactly four: an increase of two.

More generally \(F+1\leq F'\leq F+k\): any old minimum cut has at most \(k\) path edges crossing forward. A path may cross the same cut more than once; assuming it contributes exactly one crossing is the mistake behind the false equality.

Hand-Calculation Checklist

  1. Check original capacities and conservation before accepting a proposed flow.
  2. Build both directions of residual capacity, retaining only positive arcs for searches.
  3. Take the minimum capacity along the entire chosen path.
  4. Update backward arcs by cancellation, not by adding physical flow backwards.
  5. Finish with a feasible flow plus a same-valued cut, and list the cut’s original forward edges.
