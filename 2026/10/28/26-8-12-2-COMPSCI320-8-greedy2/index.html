Dijkstra’s Algorithm

Single-Pair Shortest Path Problem

Single-Pair Shortest Problem
Given a digraph \(G = (V, E)\), edge lengths \(l_e \geq 0\), source \(s \in V\), and destination \(t \in V\), find a shortest directed path from \(s\) to \(t\).

Single-Source Shortest Paths Problem

Single-Source Shortest Path Problem
Given a digraph \(G = (V, E)\), edge lengths \(l_e \geq 0\), source \(s \in V\), find a shortest directed path from \(s\) to every node.

Assumption. There exists a path from \(s\) to every node.

Dijkstra’s Algorithm

Greedy Approach. Maintain a set of explored nodes \(S\) for which algorithm has determined \(d[u]\) = length of a shortest \(s \to u\) path.

  • Initialize \(S \leftarrow \{ s \}\), \(d[s] \leftarrow 0\).

  • Repeatedly choose unexplored node \(v \notin S\) which minimizes \[ \pi(v) = \min_{e = (u, v): u \in S}d[u] + l_e \]

    add \(v\) to \(S\), and set \(d[v] \leftarrow \pi(v)\).

  • To recover path, set \(pred[v] \leftarrow e\) that achieves min.

Proof of Correctness

Invariant. For each node \(u \in S\), \(d[u] =\) length of a shortest \(s \to u\) path.

Pf. [by induction]

Base Case. \(|S| = 1\) is easy since \(S = \{s\}\) and \(d[s] = 0\).

Inductive Hypothesis. Assume \(|S| \geq 1\).

  • Let \(v\) be next node added to \(S\), and let \((u, v)\) be the final edge.
  • A shortest \(s \to u\) path plus \((u, v)\) is an \(s \to v\) path of length \(\pi(v)\).
  • Consider any other \(s \to v\) path \(P\). We need to show that it is no shorter than \(\pi(v)\). \[l(P) \geq \pi(v)\]
  • Let \(e = (x, y)\) be the first edge in \(P\) that leaves \(S\), and let \(P'\) be the subpath from \(s\) to \(x\).
  • Then we can infer:
    \[ \begin{align} l(P) &\geq l(P') + l_e (\text{non-negative lengths}) \\ &\geq d[x] + l_e (\text{inductive hypothesis}) \\ &\geq \pi(y) (\text{definition of }\pi(y)) \\ &\geq \pi(v) (\text{algo chose } v \text{ instead of } y) \end{align} \]

Efficient Implementation

Implementation.

  • Algorithm maintains \(\pi[v]\) for each node \(v\).
  • Priority queue stores unexplored nodes, using \(\pi[\cdot]\) as priorities.
  • Once \(u\) is deleted from the PQ, \(\pi[u] =\) length of a shortest \(s \to u\) path.
\begin{algorithm}
\caption{Dijkstra}
\begin{algorithmic}
\PROCEDURE{Dijkstra}{$V, E, l, s$}
    \FORALL{$v \in V \setminus \{s\}$}
        \STATE $\pi[v] \gets \infty$; $pred[v] \gets \mathrm{null}$
    \ENDFOR
    \STATE $\pi[s] \gets 0$
    \STATE Create an empty priority queue $pq$
    \FORALL{$v \in V$}
        \STATE \CALL{Insert}{$pq, v, \pi[v]$}
    \ENDFOR
    \WHILE{\CALL{Is-Not-Empty}{$pq$}}
        \STATE $u \gets$ \CALL{Del-Min}{$pq$}
        \FORALL{edge $e = (u, v) \in E$ leaving $u$}
            \IF{$\pi[v] > \pi[u] + l_e$}
                \STATE \CALL{Decrease-Key}{$pq, v, \pi[u] + l_e$}
                \STATE $\pi[v] \gets \pi[u] + l_e$; $pred[v] \gets e$
            \ENDIF
        \ENDFOR
    \ENDWHILE
\ENDPROCEDURE
\end{algorithmic}
\end{algorithm}

Which Priority Queue?

Performance. depends on PQ: \(n\) Insert, \(n\) DeleteMin, \(\leq m\) DecreaseKey.

  • Array implementation optimal for dense graphs. \(\Theta(n^2)\) edges.
  • Binary heap much faster for sparse graphs. \(\Theta(n)\) edges.
  • 4-way heap worth the trouble in performance-critical situations.
priority queue Insert Del-Min Decrease-Key total
unordered array \(O(1)\) \(O(n)\) \(O(1)\) \(O(n^2)\)
binary heap \(O(\log n)\) \(O(\log n)\) \(O(\log n)\) \(O(m \log n)\)
d-way heap \(O(d \log_d n)\) \(O(d\log_d n)\) \(O(\log_d n)\) \(O(m \log_{m / n} n)\)
Fobinacci heap \(O(1)\) \(O(\log n)\) \(O(1)\) \(O(m + n \log n)\)
integer priority queue \(O(1)\) \(O(\log \log n)\) \(O(1)\) \(O(m + n \log \log n)\)

Extensions of Dijkstra’s Algorithm

Dijkstra’s algorithm and proof can be extended to serveral related problems:

  • Shortest paths in undirected graphs: \(\pi[v] \leq \pi[u] + l(u, v)\).
  • Maximum capacity paths: \(\pi[v] \geq \min \{ \pi[u], c(u, v) \}\).
  • Maximum reliability paths: \(\pi[v] \geq \pi[u] \times \gamma(u, v)\) .
  • …

Key algebraic structure. Closed semiring (min-plus, bottleneck, Viterbi, …).

Minimum Spanning Trees

Cycles

Path
A path is a sequence of edges which connects a sequence of nodes.
Cycle
A cycle is a path with no repeated nodes or edges other than the starting and ending nodes.

Cuts

Cut
A cut is a partition of the nodes into two nonempty subsets \(S\) and \(V – S\).
Cutset
The cutset of a cut \(S\) is the set of edges with exactly one endpoint in \(S\).

Cycle–Cut Intersection

Proposition. A cycle and a cutset intersect in an even number of edges.

Spanning Tree

Spanning Tree
Let \(H = (V, T)\) be a subgraph of an undirected graph \(G = (V, E)\). \(H\) is a spanning tree of \(G\) if \(H\) is both acyclic and connected.

Proposition. Let \(H = (V, T)\) be a subgraph of an undirected graph \(G = (V, E)\). Then the following are equivalent.

  • \(H\) is a spanning tree of \(G\).
  • \(H\) is acyclic and connected.
  • \(H\) is connected and has \(|V| - 1\) edges.
  • \(H\) is acylic and has \(|V| - 1\) edges.
  • \(H\) is minimally connected: removing any edge disconnects it.
  • \(H\) is maximally acylic: adding any edge creates a cycle.

Minimum Spanning Trees

Minimum spanning tree (MST)
Given a connected, undirected graph \(G = (V, E)\) with edge costs \(c_e\), a minimum spanning tree \((V, T)\) is a spanning tree of \(G\) such that the sum of the edge costs in \(T\) is minimized.
Cayley’s Theorem
The complete graph on \(n\) nodes has \(n^{n–2}\) spanning trees.

Cannot solve by brute force.

Fundamental Cycle

Let \(H = (V, T)\) be a spanning tree of \(G = (V, E)\).

  • For any non-tree edge \(e \in E : T \cup \{ e \}\) contains a unique cycle, say \(C\).
  • For any edge \(f \in C : T \cup \{ e \} – \{ f \}\) is a spanning tree.

Observation. If \(c_e < c_f\), then \((V, T)\) is not an MST.

The Greedy Algorithm

Red Rule.

  • Let \(C\) be a cycle with no red edges.
  • Select an uncolored edge of \(C\) of max cost and color it red.

Blue Rule.

  • Let \(D\) be a cutset with no blue edges.
  • Select an uncolored edge in \(D\) of min cost and color it blue.

Greedy Algorithm.

  • Apply the red and blue rules (nondeterministically!) until all edges are colored. The blue edges form an MST.
  • Note: can stop once \(n – 1\) edges colored blue.

Proof of Correctness

Color Invariant. There exists an MST \((V, T^*)\) containing every blue edge and no red edge.

Pf. [by induction on number of iterations]

Blue.

Suppose color invariant true before blue rule.

Let \(D\) be chosen cutset, and let \(f\) be edge colored blue.

If \(f \in T^*\), then \(T^*\) still satisfies invariant.

Otherwise, consider fundamental cycle \(C\) by adding \(f\) to \(T^*\).

Let \(e \in C\) be another edge in \(D\).

\(e\) is uncolored and \(c_e \geq c_f\) since

  • \(e \in T^* \Rightarrow e\) not red.
  • blue rule \(\Rightarrow e\) not blue and \(c_e \geq c_f\).

Thus, \(T^* \cup \{f\} - \{e\}\) satisfies invariant.

Red.

Suppose color invariant true before red rule.

Let \(C\) be chosen cycle, and let \(e\) be edge colored red.

If \(e \notin T^*\), then \(T^*\) satisfies invariant.

Otherwise, consider fundamental cutset \(D\) by deleting \(e\) from \(T^*\).

Let \(f \in D\) be another edge in \(C\).

\(f\) is uncolored and \(c_e \geq c_f\) since

  • \(f \notin T^* \Rightarrow f\) not blue.
  • red rule \(\Rightarrow f\) not red and \(c_e \geq c_f\).

Thus, \(T^* \cup \{f\} - \{e\}\) satisfies invariant.

Theorem. The greedy algorithm terminates. Blue edges form an MST.

Pf. We need to show that either the red or blue or both applies.

Suppose edge \(e\) is left uncolored. Blue edges forms a forest.

Case 1. Both endpoints of \(e\) are in same blue tree. \(\Rightarrow\) Apply red rule to cycle formed by adding \(e\) to blue forest.

Case 2. Both endpoints of \(e\) are in different blue trees. \(\Rightarrow\) Apply blue rule to cutset induced by adding either of blue forest.

Prim, Kruskal, Boruvka

Prim’s Algorithm

Initiallise \(S =\) any node, \(T = \varnothing\).

Repeat \(n - 1\) times:

  • Add to \(T\) a min-cost edge with one endpoint in $.
  • Add new node to \(S\).

Theorem. Prim’s algorithm computes an MST.

Pf.

Special case of greedy algorithm. (Blue rule is repeatedly applied to \(S\).)

Prim’s Algorithm: Implementation

Theorem. Prim’s algorithm can be implemented to run in \(O(m \log n)\) time.

\begin{algorithm}
\caption{Prim}
\begin{algorithmic}
\PROCEDURE{Prim}{$V, E, c$}
    \STATE $S \gets \emptyset$; $T \gets \emptyset$
    \STATE $s \gets$ any node in $V$
    \FORALL{$v \in V \setminus \{s\}$}
        \STATE $\pi[v] \gets \infty$; $pred[v] \gets \mathrm{null}$
    \ENDFOR
    \STATE $\pi[s] \gets 0$
    \STATE Create an empty priority queue $pq$
    \FORALL{$v \in V$}
        \STATE \CALL{Insert}{$pq, v, \pi[v]$}
    \ENDFOR
    \WHILE{\CALL{Is-Not-Empty}{$pq$}}
        \STATE $u \gets$ \CALL{Del-Min}{$pq$}
        \STATE $S \gets S \cup \{u\}$
        \IF{$u \neq s$}
            \STATE $T \gets T \cup \{pred[u]\}$
        \ENDIF
        \FORALL{edge $e = (u, v) \in E$ with $v \notin S$}
            \IF{$c_e < \pi[v]$}
                \STATE \CALL{Decrease-Key}{$pq, v, c_e$}
                \STATE $\pi[v] \gets c_e$; $pred[v] \gets e$
            \ENDIF
        \ENDFOR
    \ENDWHILE
\ENDPROCEDURE
\end{algorithmic}
\end{algorithm}

Here, \(\pi[v]\) is the cost of the cheapest known edge between \(v\) and \(S\). The initial node \(s\) has no predecessor edge, so it is skipped when adding edges to \(T\); this makes explicit the root case omitted in the lecture pseudocode.

Kruskal’s Algorithm

Consider edges in ascending order of cost:

Add to tree unless it would create a cycle.

Theorem. Kruskal’s algorithm computes an MST.

Pf.

Special case of greedy algorithm.

Case 1. Both endpoints of \(e\) in same blue tree. All other edges in cycle are blue. \(\Rightarrow\) Color \(e\) red by applying red rule to unique cycle.

Case 2. Both endpoints of \(e\) in different blue trees. No edge in cutset has smaller cost(since Kruskal chose it first). \(\Rightarrow\) Color \(e\) blue by applying blue rule to cutset defined by either tree.

Kruskal’s Algorithm: Implementation

Theorem. Kruskal’s algorithm can be implemented to run in \(O(m \log m)\) time.

\begin{algorithm}
\caption{Kruskal}
\begin{algorithmic}
\PROCEDURE{Kruskal}{$V, E, c$}
    \STATE Sort $m$ edges by cost and renumber so that $c(e_1) \leq c(e_2) \leq \cdots \leq c(e_m)$
    \STATE $T \gets \emptyset$
    \FORALL{$v \in V$}
        \STATE \CALL{Make-Set}{$v$}
    \ENDFOR
    \FOR{$i \gets 1$ \TO $m$}
        \STATE $(u, v) \gets e_i$
        \IF{\CALL{Find-Set}{$u$} $\neq$ \CALL{Find-Set}{$v$}}
            \STATE $T \gets T \cup \{e_i\}$
            \STATE \CALL{Union}{$u, v$} \COMMENT{Merge the components containing $u$ and $v$}
        \ENDIF
    \ENDFOR
    \RETURN $T$
\ENDPROCEDURE
\end{algorithmic}
\end{algorithm}

Reverse-Delete Algorithm

Start with all edges in \(T\) and consider them in descending order of cost, delete edge from \(T\) unless it would disconnect \(T\).

Theorem. The reverse-delete algorithm computes an MST.

Pf. Special case of greedy algorithm.

Case 1. Deleting edge does not disconnect \(T \Rightarrow\) Apply red rule to cycle \(C\) by adding \(e\) to another path in \(T\) between its two end points.

Case 2. Deleting edge disconnects \(T \Rightarrow\) Apply blue rule to curset \(D\) induced by either component.

Borůvka’s Algorithm

Repeat until only one tree:

  • Apply blue rule to cutset corresponding to each blue tree.
  • Color all selected edges blue.

Borůvka’s Algorithm: Implementation

Borůvka’s algorithm can be implemented to run in \(O(m \log n)\) time.

Contract version

  • After each phase, contract each blue tree to a single supernode.
  • Delete self-loops and parallel edges, keeping only the cheapest one.
  • Borůvka phase becomes: take cheapest edge incident to each node.

Problem. Given a graph \(G = (V, E)\) and a set of edges \(F\), contract all edges in \(F\), removing any self-loops or parallel edges.

Borůvka’s Algorithm on Planar Graphs

Theorem. Borůvka’s algorithm (contraction version) can be implemented to run in \(O(n)\) time on planar graphs.

A Hybrid Algorithm

Borůvka–Prim algorithm.

  • Run Borůvka (contraction version) for \(\log_2 \log_2 n\) phases.
  • Run Prim on resulting, contracted graph.

Single-Link Clustering

Clustering

\(k\)-Clustering
Given a set \(U\) of \(n\) objects labeled \(p_1, \ldots, p_n\), partition into \(k\) clusters so that objects in different clusters are far apart.

Clustering of Maximum Spacing

Distace Function
Numeric value specifying “closeness” of two objects.
  • \(d(p_i, p_j) = 0\) iff \(p_i = p_j\).
  • \(d(p_i, p_j) \geq 0\).
  • \(d(p_i, p_j) = d(p_j, p_i)\).
Spacing
Min distance between any pair of points in different clusters.
Goal
Given an integer \(k\), find a \(k\)-clustering of maximum spacing.

Greedy Clustering Algorithm: Analysis

Theorem. Let \(C^*\) denote the clustering \(C^*_1, \dots, C^*_k\) formed by deleting the \(k – 1\) longest edges of an MST. Then, \(C^*\) is a \(k\)-clustering of max spacing.

Pf.

  • Let \(C\) denote any other clustering \(C_1, \ldots, C_n\).
  • Let \(p_i\), \(p_j\) be in the same cluster in \(C^*\), say \(C^*_r\), but different cluster in \(C\), say \(C_s\) and \(C_r\).
  • Some edge \((p, q)\) in \(p_i - p_j\) path in \(C^*_r\) spans two different clusters in \(C\).
  • Spacing of \(C^* =\) length \(d^*\) of the \((k - 1)\)st longest edge in MST.
  • Edge \((p, q)\) has length \(\leq d^*\) since it wasn’t deleted.
  • Spacing of \(C\) is \(\leq d^*\) since \(p\) and \(q\) are in different clusters.

Min-Cost Arborescences

Arborescences

Arborescences
Given a digraph \(G = (V, E)\) and a root \(r \in V\), an arborescence rooted at \(r\) is a subgraph \(T = (V, F)\) such that
  • \(T\) is a spanning tree of \(G\) if we ignore the edge direction.
  • There is a unique directed path in \(T\) from \(r\) to each other node \(v \in V\).

Proposition. A subgraph \(T = (V, F)\) of \(G\) is an arborescence rooted at \(r\) iff \(T\) has no directed cycles and each node \(v \neq r\) has exactly one entering edge.

Pf.

\(\Rightarrow\) If \(T\) is an arborescence, then it has no directed cycles, and every node \(v \neq r\) has exactly one entering edge: the last edge on the unique \(r \to v\) path.

\(\Leftarrow\) Suppose \(T\) has no directed cycles and each node \(v \neq r\) has exactly one entering edge.

  • To construct an \(r \to v\) path, start at \(v\) and repeatedly follow entering edges in the backward direction.
  • Since \(T\) is finite and has no directed cycles, this process must terminate at a node with no entering edge.
  • It must terminate at \(r\), since every other node has an entering edge. Thus, \(r\) has no entering edge, and reversing the traced sequence gives an \(r \to v\) path.
  • The path is unique because each node other than \(r\) has exactly one entering edge. Also, \(T\) has \(|V| - 1\) edges and is connected when edge directions are ignored, so it is a spanning tree.

Therefore, \(T\) is an arborescence rooted at \(r\).

Min-Cost Arborescences Problem

Assumption 1. All nodes are reachable from \(r\).

Assumption 2. No edges enters \(r\).

Min-Cost Arborescence Problem
Given a digraph \(G\) with a root node \(r\) and edge costs \(c_e \geq 0\), find an arborescence rooted at \(r\) of minimum cost.

A Sufficient Optimality Condition

Property. For each node \(v \neq r\), choose a cheapest edge entering \(v\) and let \(F^*\) denote this set of \(n – 1\) edges. If \((V, F*)\) is an arborescence, then it is a min-cost arborescence.

Note. \(F^*\) may not be an arborescence (since it may have directed cycles).

Reduced Costs

Reduced Cost
For each \(v \neq r\), let \(y(v)\) denote the min cost of any edge entering \(v\). Define the reduced cost of an edge \((u, v)\) as \(c'(u, v) = c(u, v) - y(v) \geq 0\).

Observation. \(T\) is a min-cost arborescence in \(G\) using costs \(c\) iff \(T\) is a min-cost arborescence in \(G\) using reduced costs \(c'\).

Edmonds Branching Algorithm

Intuition. Recall \(F^* =\) set of cheapest edges entering \(v\) for each \(v \neq r\).

  • All edges in \(F^*\) have 0 cost with respect to reduced costs \(c'(u, v)\).
  • If \(F^*\) does not contain a cycle, then \((V, F^*)\) is a min-cost arborescence.
  • If \(F^*\) contains a cycle \(C\), we can use edges in \(C\) without increasing the reduced cost.
  • Contract the edges in \(C\) to a single supernode, removing any self-loops.
  • Recursively solve the problem in the contracted network \(G'\) with reduced costs \(c'\).
\begin{algorithm}
\caption{Edmonds-Branching}
\begin{algorithmic}
\PROCEDURE{Edmonds-Branching}{$G, r, c$}
    \FORALL{$v \in V \setminus \{r\}$}
        \STATE $y(v) \gets$ minimum cost of any edge entering $v$
        \FORALL{edge $(u, v)$ entering $v$}
            \STATE $c'(u, v) \gets c(u, v) - y(v)$
        \ENDFOR
    \ENDFOR
    \STATE $F^* \gets \emptyset$
    \FORALL{$v \in V \setminus \{r\}$}
        \STATE Choose one 0-cost edge $e$ entering $v$ under costs $c'$
        \STATE $F^* \gets F^* \cup \{e\}$
    \ENDFOR
    \IF{$(V, F^*)$ is an arborescence rooted at $r$}
        \RETURN $T = (V, F^*)$
    \ELSE
        \STATE $C \gets$ a directed cycle in $F^*$
        \STATE Contract $C$ to a single supernode, yielding $G' = (V', E')$
        \STATE $T' \gets$ \CALL{Edmonds-Branching}{$G', r, c'$}
        \STATE Extend $T'$ to an arborescence $T$ in $G$ by adding all but one edge of $C$
    \ENDIF
    \RETURN $T$
\ENDPROCEDURE
\end{algorithmic}
\end{algorithm}

Notes. The reduced-cost assignment uses \(c'(u, v) = c(u, v) - y(v)\), as defined above; the lecture pseudocode writes \(c'\) on both sides without initializing it. When expanding the contracted cycle, restore the original edges represented by \(T'\). If its edge entering the supernode enters \(C\) at vertex \(b\), omit the cycle edge entering \(b\) and add all other edges of \(C\).

Min-Cost Aborescence

Theorem. There exists an \(O(m + n \log n)\) time algorithm to compute a min-cost arborescence.
