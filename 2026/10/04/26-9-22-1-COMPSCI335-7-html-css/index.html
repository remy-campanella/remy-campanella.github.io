HTML

HTML

HTML stands for Hypertext Markup Language, developed by Sir Tim Berners-Lee around 1990s.

An Example

DOCTYPE tells a browser the version of the HTML document. It is an artifact of the history of HTML. The content of the DOCTYPE changed through versions, and HTML5 simplified it to just this: <!DOCTYPE html> meaning the current version of HTML.

The root element of the HTML document is <html> which contains two child elements: <head> and <body>.

  • The <body> element contains the data we see displayed on the browser.
  • The <head> element contains metadata (that helps to render the data in the <body>). For example, <title> is not displayed in the HTML display of the browser, but browsers typically show this title in the browser window’s title bar.

Elements

Head and Body

HTML Elements

An element contains a start tag, an end tag, and content in between. The start and end tags describe the content within tags, which is also known the value if the element.

Sematic Elements

Semantic elements define the meaning of the content they contain.

Text Composition

We have elements to specify italics <i>, boldface <b>, emphasize <em>, underline <u>, and strikethrough <s>.

<pre> contains preformatted text. That’ll be rendered exactly as they are written, using monospaced font. <pre> is used if we want to display a code fragment.

Commonly Used HTML Elements

  • <h1> ~ <h6>: Headings.
  • <p>: Paragraph.

<div> and <span>

Both are containers. There are no semantic meaning to these containers. They simply are used for grouping and organization.

  • The <div> containers identify block sections.
  • Similarly the <span> containers identify inline sections.

Attributes and More Elements

Attribute

HTML elements can have attributes attached to them.

  • E.g., <a href="https://dividni.com">Dividni</a>
  • The attribute values are quoted. Both "" and '' are fine.

The attribute lang of <html lang="en"> specifies the language of the document (e.g., en for English).

Hyperlink

Hyperlinks are called anchors.

In-Page navigation is achieved by using element IDs and referring to these element IDs within the anchors.

Hyperlink

This will link to an element with id="Hyperlink".

iframe

The iframe element allows us to embed someone else’s web content in our own HTML.

We can embed a video using iframe.

List & Tables

HTML Lists

  • Ordered list: <ol>
  • Unordered list: <ul>
  • List contain list items: <li>

Ordered lists have a type attribute. Value 1 is decimal number, a is lowercase alpha, A uppercase alpha, i is roman lowercase numerals, and I is roman uppercase numerals.

HTML Tables

  • Tables are denoted by <table>.
  • Each table has a number of rows: <tr>
  • Each row has a number of data cells (making up the columns): <td>
  • We can also have heading cells replacing some of the data cells: <th>

As tables get more complex, one can add further structure by using <thead>, <tbody>, and <tfoot> elements to the tables.

Void Elements

Most HTML elements contain some content. E.g., <p>Hello!</p> or <p><em>Hello!</em><p>. Some HTML elements have no content, i.e., contain nothing – no text nor child elements These are called void elements.

The following are some common examples of void elements: <br>(line break), <hr>(horizontal line), <img>, <input>, <link>, <meta>, <embed>.

Void elements has no closing tag, but use self-closing.

Images

The mandatory alt attribute contains a textual replacement for the image and is useful for accessibility.

Video and Audio

We can have multiple <source> tags within <video> and <audio>. This lets us define multiple files for the browser to choose from. The browser selects the first <source> it can support.

User Input

The <form> element provides a semantic container for related input items, making it a better choice than a non-semantic <div> for user input. However, the browser automatically handles form submission and validation, which often leads to unexpected behaviour if not properly controlled using JavaScript. Avoid using <form>s, and use <div> instead – at least when we are learning the ropes.

Buttons

We must use the type attribute of the button tag to explicitly state the type of the button. We shall not rely on the default type. Generally, we will want to use the type button as the example above shows. For the curious, the default button type is submit which can throw curveballs.

Unicode and Entities

Unicode Characters

HTML understands Unicode much like any other modern computer language does. To use Unicode, add <meta charset="utf-8"/> to the <head> element as the very first element of <head>.

HTML Entities

In the past, HTML had the so-called HTML entities that allowed us to add certain symbols: e.g., &copy; is the entity that denotes the copyright symbol ©.

These are no longer required since we can use Unicode symbols directly in HTML, improving readability considerably.

However, there are four special entities that we commonly use.

Character Entities Render
< &lt; <
> &gt; >
& &amp; &
non-breaking space &nbsp;  

Closing Remarks

Custom Attributes

Custom data-* attributes allow us to embed custom, private data into HTML elements.

Custom data-* attributes are useful when we need to add metadata to table cells, flexboxes, etc.

Cascading Stylesheet(CSS)

CSS is a language that describes the presentation aspects(look & format) of an HTML document. It controls how HTML elements are displayed, including layout, colors, fonts, and responsiveness. This allows separation of concerns between the document’s content and the document’s presentation. “Cascading” refers to how styles are applied in a hierarchy, resolving conflicts between multiple style rules.

Styling Basics

Inline Styles

Inline styles are for one-off styling or for small adjustments. They are not scalable or reusable.

Internal Styles

Internal styles are useful when used in a single HTML page However, they are not reusable if we want to use them across multiple HTML pages.

External Styles

The styles are in a separate file and therefore are reusable across multiple HTML pages.

  • Easier maintenance
  • Suits large projects quite well
  • Since the styles are external, we need an additional HTTP request to the server to fetch the style file

CSS Syntax

Format:

Selector

The element selector (such as the h1 { ... } we saw earlier) is a basic selector that allows selecting all the named elements (such as h1, in our example).

We also have a universal selector, written *, that selects all elements.

ID Selector

Instances of an HTML element (e.g., <h1 id="header-1">) can be separately styled.

Class Selector

Classes allow us to style related instances of many HTML elements together. Such instances are uniquely identified by a class attribute of the HTML element.

Grouping Selectors

Grouping selectors help us to apply the same style to multiple elements.

Descendant Selector

Descendant selectors target elements nested inside others.

Combinators

Child div > p will find the direct children p of div.

Adjacent sibling h2 + p will select the element <p> immediately following another element <h2>.

General sibiling h2 ~ p selects all matching siblings <p> that follow another element <p>.

Common CSS Properties

Property Meaning
color Text color.
font-size Size of the font.
font-family Type of font.
font-weight Weight of the font.
text-align Horizontal alignment (e.g., left, center, right).
text-decoration Adds decoration like underline or none.
background-color background color of an element.
background-image Adds an image as the background.

CSS Box Model

The box model is the foundation of layout in CSS. It consists of:

  • Content: The content inside the element.
  • Border: The edge of the element.
  • Padding: Space between the content and the border.
  • Margin: Space between the element and others.

Centering a Block Element

To center a block element horizontally, we set margin to auto and define a specific width for the element.

width: 50% makes the element take up 50% of the container’s width, and the margin ensures it’s centered.

The Display CSS Property

Block vs. Inline Display

Block elements display one after the other like paragraphs in a document(<p>, <ol>, <ul>, and <div>).

Inline elements display one after the other like words in sentence(<a>, <b>, <i>, and <span>).

A block element can contain an inline element, but an inline element cannot contain a block element.

The display property in CSS is a fundamental layout tool that controls how an element is visually formatted in the flow of the HTML document. It determines how an element behaves—whether it appears at all, takes up space, or how it interacts with other elements.

Style: display: none

This completely removes the element from the rendering flow of the page.

The element will not be visible, and it does not occupy any space in the layout.

This is an important mechanism we use for hiding elements based on conditions (e.g., menus, modals). We also use it to toggle visibility without deleting the element from the HTML.

If we hide an element using display: none and subsequently want to show the element, we would restore the original display status of the element.

  • If the element is an inline element(such as <a>, <b>, <i>, and <span>), then we restore the element using display: inline to show the element.

  • If the element is a block element(such as <p>, <ol>, <ul>, and <div>), then we restore the element using display: block to show the element.

Style: visibility: hidden

With visibility:hidden, the element remains in the layout(like a ghost) and still occupies space in the page flow. We just can’t see it, and it is non-interactive.

When displaying a status message, we may want to show or hide it without affecting the layout of the page. In this case, using the visibility property is more appropriate than display, because it hides the element visually while still preserving its space in the layout.

The CSS Opacity Property

The opacity property in CSS controls the transparency level of an element, from 0(fully transparent) to 1(fully opaque).

Opacity is inherited by child elements, meaning any nested elements will also have the same opacity.

Example: an opacity of 0.5 makes the element 50% transparent, allowing elements behind it to be partially visible.

Flexbox

Flexible Displays

Flexbox provides an efficient and predictable way to arrange elements, especially when these elements have dynamic or unknown sizes. These elements are called the “flex items”. They will sit in a “flex container” and will be arranged nicely in this container automatically.

The display value flex will set up a container for flexible display items.

Change to flex-wrap: nowrap;

The :nth-child

Pseudo-Class Selectors

A pseudo-class selector is a keyword added to a selector that targets elements based on their state or position. :first-child matches the first child of the parent, :last-child matches the last child of the parent.

Here element is any HTML tag.

The :nth-child

The :nth-child() pseudo-class in CSS is a powerful selector used to target elements based on their position within their parent element.

Here element is any HTML tag. The parameter x is a value (such as 2), a constant (such as odd or even) or a formula (an + b). In the formula an + b, a is a step value, and b is the starting point.

Media Queries

Media Queries

Media queries let us apply CSS styles based on the device’s media type (like screen or print) and specific features such as screen resolution, orientation, or aspect ratio.

media-queries.html

We have indicated a specific style for print media: the display property of the elements that have been classed non-printable is set to none. In other words, in a print media elements that are marked non-printable will not show (i.e., will not print).

all

The all shorthand CSS property resets all of an element’s properties.

In media queries, one very practical use case of the all property is to completely reset styles, allowing us to redefine specific styles from scratch, rather than trying to override each conflicting rule.

Remove all styles, including margins, font settings, layout, etc., even those from the browser’s default stylesheet for all (*) elements on the page when the page is being printed and the print layout is landscape. After resetting everything, explicitly set the text color to blue.

Best Practice

Mobile-first design: start with styles for smaller screens (i.e., default styles are for smaller screens) and add media queries for larger screens

Breakpoints for media queries should based on screen widths of typical (!) devices.

Avoid hardcoding pixel values. Prefer to use relative units such as em, rem, and %.

The unit em is relative to the font size of the parent element, while the unit rem is relative to the font size of the root element (this is <html> usually).

Cascading and Specificity

CSS is built around a key idea called the cascade. This means that styles can come from different places — like the browser, the website’s code, or even the user — and all work together to style a webpage.

Sometimes, different rules try to style the same thing in different ways.

But in the end, only one rule can win.

The cascade & specificity help decide which rule is the one that gets applied.

CSS Cascading

Styles are specified in three contexts: browser (the default styles a browser uses), the content-creator or author, and user (via user preferences). These contexts are known as origins.

In addition, each origin may optionally mark certain rules to be important(using the keyword !important). An important rules tells the browser: “This rule should win, no matter what other styles say — unless they are also marked !important and have higher precedence.”

CSS rules from different origin types are applied based on a cascade order of importance. These are from low to high priority:

  • User-agent styles
  • User styles
  • Author styles
  • Author styles with !important
  • User styles with !important
  • User-agent styles with !important (these are very rare)

CSS Specificity

Specificity is the algorithm browsers use to determine which CSS declaration is most relevant to an element, ultimately deciding the applied property value. It calculates the weight of a CSS selector to resolve conflicts between competing declarations.

When multiple rules specify different values for the same element, the declaration with the selector that has the highest specificity takes precedence.

The last rule defined in the source takes precedence when specificity is equal.

There are three selector weight categories

  • ID column which includes ID selectors such as #course. This column has the highest specificity
  • CLASS column which includes class selectors such as .courses. This column has the second highest specificity
  • TYPE column that includes element selectors such as h1 and span. This has the lowest specificity

The universal selector (*) is not counted and does not contribute to the specificity.

The specificity values are expressed in this form: x-y-z where x, y, and z refer to the weights derived from ID, CLASS and TYPE respectively.
