SVG

SVG

SVG is a vector-based graphic format for the Web and is defined using an XML-like syntax.

SVG specifies a collection of graphical objects (such as lines and circles).

  • SVG defines the geometry of objects using mathematical descriptions rather than pixels, which means the shapes can scale infinitely without losing clarity or becoming pixelated.

Being a vector format, it does not lose quality during resizing or zooming.

SVG Example

This SVG element describes a simple red line within a 300×200 pixel canvas.

Canvas (<svg>):

  • Size: 300 pixels wide and 200 pixels high

Line (<line>):

  • Starts at \((10, 30)\)
  • Ends at \((100, 200)\)
  • Stroke colour: Red
  • Stroke width: 5 units (pixels, by default)

Coordinate System

A coordinate system is like graph paper that helps SVG know where to draw things — like circles, rectangles, lines, and text. The top-left corner is point \((0, 0)\). The X-axis goes right, and the Y-axis goes down.

viewBox

The viewBox attribute says which part of the SVG canvas is being viewed. It also says how to scale the SVG to fit the screen (or container).

When working with an SVG canvas of width × height, it is best practice to set the viewBox to 0 0 <width> <height>, especially for creating scalable and responsive SVGs. Setting the viewBox without setting the width and height gives us a responsive SVG that scales to container maintaing aspect ratio. The container element (such as a <div>) can then be used to control the actual display size in a responsive manner.

SVG and HTML

SVG and HTML

SVG can be embedded directly in HTML using <svg> tag. Such inlined SVGs provide more control and interactivity.

We can also include external SVGs in HTML. <img> can point to an SVG image. The (favourite) icon could be an SVG.
