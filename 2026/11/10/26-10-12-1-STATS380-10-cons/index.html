Handling Missing Values on Import

The Young People worksheet uses an underscore to mark missing values. Handle this in getTable() during import so later reshaping and plotting can work with numeric data. na.strings = c("NA", "_") keeps the existing "NA" marker as well. Even with na.rm = TRUE, a column containing only missing values has no finite range to plot.

After the change, run regression checks on the Children tables that were already readable. Also check that underscores in the Young People tables become NA and that the measure column is numeric. Match the types and column structure of the reference and actual results before comparing, so representation differences introduced by CSV import or export are distinguishable from value changes.

Extracting Tables from Multiple Worksheets

tableInfo() supplies metadata for the tables in a worksheet, and tableBy() calls the rate or proportion reader based on the table type. The example uses these two lecture helpers. mapply() pairs up each table’s arguments, while MoreArgs supplies the same file path and years to every call for that worksheet.

The result is a named, nested list. The outer list is indexed by worksheet. Within each entry, info stores the extraction metadata and tables stores the long tables by name. SIMPLIFY = FALSE keeps each table as a separate data frame.

Comparing Tables Across Worksheets

A list organised by worksheet is convenient for batch import. To compare releases, regroup the results by table name. For example, extract the Ethnic group table from each release, add a source column and combine the rows. Earlier releases can lack tables introduced later, so look up tables by name and check that the columns are compatible. The lectures also standardise older age-group labels to align with Children and Young-people.

After combining the rows, distinguish the observation year from the report release. The same observation year can appear in several releases. Group plots by ethnicity and draw a separate line for each release to show differences in overlapping years. If labels or statistical definitions changed, check how the source tables define their measures.

Automating Conversion, Saving Results and Organising Files

  • Automated conversion. The lectures use readxl::excel_sheets() to list worksheets, select sheets by name and read them with readxl::read_xlsx(). Output filenames are built from the report year and sheet name. The outer iteration works over workbooks and the inner iteration over the selected sheets.
  • Serialisation. Use write.csv(table, path, row.names = FALSE) to save extracted tables. Include the sheet and table names in the output path so the files can be reviewed and used in regression checks. CSV is portable, but check column names, types and missing values when reading it back. Use saveRDS() and readRDS() to preserve R object classes and attributes.
  • File organisation. Keep original workbooks, converted CSVs, R functions, tests and generated results in separate directories. Use file.path() to build paths, list.files() to enumerate inputs and source() to load functions in dependency order. This gives each result a reproducible path back to the original workbook.
