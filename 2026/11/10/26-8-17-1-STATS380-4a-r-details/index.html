Classes, Attributes and Generic Functions

An R object’s underlying type and its class can differ. Use typeof() to see its storage type, mode() for a broader classification, and class() to see its class. A factor is stored as integers, while mode() groups integers and doubles under "numeric". A data frame is stored as a list.

names, dim, dimnames, levels and an explicitly set class are examples of attributes. Use attributes(x) to inspect them all and attr(x, "label") to get or set a single attribute. class(x) can also infer a class from the object’s type and dimensions.

S3 generics such as print() and summary() choose a method based on the object’s class. For example, print(d) uses the data-frame printing method. The selected method determines the result or side effect.

Dates and Date-Times

Date stores days relative to 1970-01-01. as.Date() parses character input, and format() converts dates into display strings. When a numeric source uses its own reference date, pass it as origin. If the source numbers the origin as day 1, subtract 1 before conversion.

%Y represents a four-digit year, %y a two-digit year, %m a month and %d a day. Subtracting two dates returns a difftime object. Calendar months vary in length, so use seq(..., by = "month") to generate monthly dates.

Use POSIXct or POSIXlt for dates with times. POSIXct stores seconds relative to 1970-01-01 UTC. POSIXlt exposes components such as the hour and day of the week. The time format codes %H, %M and %S represent hours, minutes and seconds.

Regular Expressions

Pattern Meaning
^, $ Start and end of the string
., [.] Any single character and a literal period
[Tt], [^0-9] T or t, and any character outside the digit range
[[:alpha:]], [[:space:]] An alphabetic character and a whitespace character
?, +, *, {n} Repeat the preceding pattern zero or one time, one or more times, zero or more times, or exactly n times, respectively

Parentheses group patterns and a vertical bar separates alternatives. For example, ^(cat|dog)$ matches the whole string "cat" or "dog".

grep() returns the indices of matching elements. Set value = TRUE to get the original matching strings. grepl() returns one logical value per element. regexpr() finds the first match in each string, while gregexpr() finds all matches. Pass the result to regmatches() to extract the matched text.

sub() replaces the first match in each string, and gsub() replaces every match. In a replacement string, "\\1" inserts the text captured by the first group. R parses the string before the regular expression engine parses the pattern, so a literal period can also be written as "\\.". For literal searches, fixed = TRUE avoids regular expression escaping.

Lexical Scope and Closures

R first looks for a name in the current call environment, then follows the chain of enclosing environments from where the function was defined. A returned inner function retains access to its defining environment. This is the closure mechanism illustrated in the lectures.

Each returned function uses its own offset. Calling force(offset) evaluates that argument before the factory returns the inner function.
