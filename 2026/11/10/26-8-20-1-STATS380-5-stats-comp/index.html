Split–Apply–Combine

Split the data into groups, apply the same function to each group, then combine the results into the required list, vector, matrix or data frame. Decide what shape the result should have before choosing how to combine it.

  • Split. split(d, d$group) returns a named list and preserves row order within each group. Factor levels determine group order, and drop = TRUE removes unused groups. Rows with missing group labels are omitted. To group by several variables, use split(d, list(d$group, d$year), drop = TRUE).
  • Apply. lapply() always returns a list. Use ... to pass additional arguments to every call. For example, lapply(groups, function(g) mean(g$value, na.rm = TRUE)) computes a mean for each group.
  • Combine. do.call(rbind, limits) passes each list element as a separate argument to rbind(). Vectors can combine into a matrix, and data frames with matching columns can combine into a data frame. Use unlist() to flatten results into a vector. Mixed atomic types are coerced to a common type.
Function Input and result
sapply(X, FUN) Tries to simplify the results. One scalar per group usually gives a vector, and equal-length vectors can give a matrix. If simplification fails, the result remains a list.
vapply(X, FUN, FUN.VALUE) Specifies the expected type and length with a template. For example, vapply(groups, nrow, integer(1)) expects one integer per group.
apply(M, 1, FUN) and apply(M, 2, FUN) Work over matrix rows and columns, respectively. A data frame can be coerced to a matrix with a common type before the function is applied.
mapply(FUN, x, y) Passes corresponding elements from several inputs. Use MoreArgs for fixed arguments and SIMPLIFY = FALSE to retain a list.
tapply(x, g, FUN) Applies a function to a vector by group and usually returns an array indexed by group.
aggregate(d["value"], list(group = d$group), FUN) Summarises the selected column within each group and returns a data frame.

The same approach works for moving averages. Each index is the start of a window. For a window of width 2, there are length(x) - 1 complete windows.

Distribution Functions and Random Numbers

Prefix Input and result Normal example
d Takes a value and returns a density or discrete point probability dnorm(x, mean, sd)
p Takes a threshold and returns the cumulative probability \(P(X \le q)\) pnorm(q, mean, sd)
q Takes a probability and returns a quantile qnorm(p, mean, sd)
r Takes a sample size and generates simulated values rnorm(n, mean, sd)

The same naming scheme applies to binom (size and prob), pois (lambda), t (df) and f (df1 and df2). A continuous distribution assigns zero probability to a single point. Subtract cumulative probabilities to find the probability of an interval. lower.tail = FALSE gives \(P(X > q)\). For an integer-valued distribution, use \(q = k-1\) to obtain \(P(X \ge k)\).

set.seed() fixes the starting point of the random number sequence. Set it once at the start of a simulation, then let the state advance. sample(x) samples without replacement by default and can shuffle a vector with more than one element. For a numeric vector that might contain one value, use x[sample.int(length(x))] to shuffle by index. This avoids the special case in which sample(5) samples from 1:5.

Checking Hypotheses by Simulation

Visual inference. Generate several datasets of the same size as the observed data under the assumed model. Plot them on the same scale and randomly place the observed data among the simulated panels. Look for features that distinguish the observed panel. The lecture example simulates beaver temperatures by adding normal errors to fitted values.

Permutation test. Hold the observations fixed and shuffle the group labels when exchangeability under the null justifies doing so. Recompute the same statistic for each shuffle, then compare the observed statistic with the simulated null distribution. The following example uses the lecture’s beaver data.

The absolute mean difference measures extremeness in either direction. Adding one to the numerator and denominator includes the observed arrangement in the comparison. If successive observations are dependent in time, check whether unrestricted shuffling is appropriate.

Simulating Sample Means

A single sample produces one sample mean. To examine its sampling distribution, repeatedly draw from a skewed exponential distribution and compare the results for different sample sizes.

For independent, identically distributed observations with finite variance, \(\operatorname{SD}(\bar X)=\sigma/\sqrt{n}\). The distribution of the standardised sample mean approaches a normal distribution as \(n\) grows. Larger samples reduce the sampling variability of the mean.
