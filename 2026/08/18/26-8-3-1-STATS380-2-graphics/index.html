The plot() Function

Creating a plot is often as simple as a single call to the plot() function. The first two arguments are x and y and the type of plot that is produced will depend on the type of values in x and y.


By executing ?plot, we can see there both exist a plot() function in {base} and {graphics}.

plot(density()) can plot the density distribution of the parameter.

plot(xlim=c(), ylim=c()) can set the limit of the plot.

Multiple Plots

Another option for plotting multiple groups of data is to draw multiple plots. The par() function has arguments that control how many plots are drawn on a page. For example, the mfrow argument is a numeric vector specifying the number of rows and columns of plots.
