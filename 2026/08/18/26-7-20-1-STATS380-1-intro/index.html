R Basics

The R Language

R is a general-purpose computer language, like Python or Java or C. This means that we can use R to instruct a computer to perform any task.

R has features that make it well-suited to working with data. For example, vectorisation means that it is very easy to create and work with a collection of values all at once.

Vectorisation means that the calculation is performed for each numeric value in b1time and the result is another vector of numeric values.

Expression

R code consists of one or more expressions. Like any computer language, R has strict rules that must be followed. If our code breaks the rules, it will cause a syntax error.

Vectors

All values in R are objects and the simplest sort of object in R is a vector. A vector can contain a single value or multiple values, but all of the values must have the same basic mode, typically either numeric or character.

Vectorisation and The Recycling Rule

Arithmetic operators in R are vectorised so if we perform a calculation with a vector of values we get a vector of values as the result.

The recycling rule says that the shorter vector will be repeated to make it the length of the longer vector and then the calculation can take place for each pair of values.

Logical Vectors

In addition to numeric and character values, we can also work with logical values in R. A logical value is one of the special symbols TRUE or FALSE.

Function which can give the TRUE indices of a logical object, allowing for array indices.

However, it is much more common for a logical vector to be the result of an expression involving a logical operator.

Type Coercion

Sometimes we need to coerce a vector of one type into another. For example, in the previous section, we began with character values representing times and extracted separate hours and minutes character vectors.

This could be used to count how many cases is satisfied.

Subsetting

Because we often deal with vectors containing multiple values, being able to extract subsets of values is another important tool in R.

Fetch value using index. We can also use vector to fetch several values. Note that index in R starts from 1. If the inde is negative vector, it means fetching subset except these.

The access out of range will return NA.

The brackets can also be filled with logical expressions. All cases make the logical expression true will be selected.

Directly use assignment to replace a value or a subset of value. This also obeys the recycling rule.

Sorting and ordering

The sort() function can be used to sort a vector (ascending by default, but the decreasing argument allows for descending order instead).

order() will give a index sequence(in vector) whose value is sorted increasing/decreasing.

Special Values

The result of some mathematical operations are either infinite or undefined.

NULL represents the null object in R: it is a reserved word. NULL is often returned by expressions and functions whose value is undefined.

Complex number is trated as NaN in base environment.

If NA participated the calculation, the result is also NA. Use na.rm in some function to omit NA.

List

list type can save diffenent types of values into one variable.

The single bracket will return a sublist, the double brackets will return the object itself.

Objects in list can also be named. Use $ to access by name.

Formula

Formulas are another sort of expression in R. Formulas allow us to express a relationship between symbols, which is useful, for example, when specifying a statistical model and for some graphics functions.

Example: Summary Statistics

We have a set of beaver body temperature measurements. A very simple model for those measurements is that they are randomly spread around a central value.

\[ X = \mu + \varepsilon \\ \varepsilon \overset{\mathrm{iid}}{\sim} \rm{Normal}(0, \sigma) \]

We can estimate \(\mu\) and \(\sigma\) from the data:

Calculate normal distribution parameters.
\[ mu = mean(temp - mu) sigma = sd(temp) t2 = (temp - mu) / sigma \]

Plot.

We could calculate the temperature deviations from \(\mu\) and look at the correlation between successive deviations. If the deviations from \(\mu\) are independent then they should not be correlated.

That seems like a quite high correlation; temperature (i) is similar to temperature ((i - 1)).
