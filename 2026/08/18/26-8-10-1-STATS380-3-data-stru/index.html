Matrices

Most of the data that we have seen so far have been vectors: a one-dimensional structure containing zero-or-more values, all of the same type (all numeric, all character, or all logical).

A matrix is a two-dimensional structure containing zero-or-more values, all of the same type.

Creating Matrices

We can create a matrix with the matrix() function. This takes a vector of values as the first argument and then subsequent arguments describe the dimensions (rows and columns) of the matrix.

Another easy way to create a matrix is with the cbind() and rbind() functions. These take multiple vectors of values and combine them as either the columns or rows of a matrix.

Character Matrices

A matrix has a mode, just like a vector; a matrix is either all numeric values, or all character values, or all logical values.

Use mode() to check element type.

The diag() function is useful for creating matrices with values only on the diagonal. This function is quite flexible; the following code generates a square diagonal matrix with ones on the diagonal by treating the first argument as the size of the matrix.

Matrix Dimensions

We can query the dimensions of a matrix with the functions dim(), nrow(), and ncol().

Naming Matrices

By default a matrix has no row or column names, which we can check using dimnames(), rownames(), and colnames().

Matrix Operations

As with vectors, matrices allow us to perform operations on multiple values at once.

Subsetting

We can subset matrices using a similar syntax fior subsetting vectors, but we require two indices, separate by a comma, to specify both rows and columns. Either index can be more than one value.

The diag() function can be used on an existing matrix to extract the diagonal elements.

Apply Functions Over Array Margins

Returns a vector or array or list of values obtained by applying a function to margins of an array or matrix.

  • X an array, including a matrix.

  • MARGIN a vector giving the subscripts which the function will be applied over. E.g., for a matrix 1 indicates rows, 2 indicates columns, c(1, 2) indicates rows and columns. Where X has named dimnames, it can be a character vector selecting dimension names.

  • FUN the function to be applied.

Sweep out Array Summaries

Return an array obtained from an input array by sweeping out a summary statistic.

  • x an array, including a matrix.

  • MARGIN a vector of indices giving the extent(s) of x which correspond to STATS. Where x has named dimnames, it can be a character vector selecting dimension names.

  • STATS the summary statistic which is to be swept out.

  • FUN the function to be used to carry out the sweep.

Outer Product of Arrays

The outer product of the arrays X and Y is the array A with dimension c(dim(X), dim(Y)) where element A[c(arrayindex.x, arrayindex.y)] = FUN(X[arrayindex.x], Y[arrayindex.y], ...).

Factors

A categorical variable is one that contains values from a fixed set of valid values.

If an undefined level is inserted, then throw a warning and produce NA.

cut divides the range of x into intervals and codes the values in x according to which interval they fall. The leftmost interval corresponds to level one, the next leftmost to level two and so on.

Data Frames

A data frame is a structure that can hold multiple vectors of data. A data frame is like a matrix, in that it has rows and columns, but it is actually fundamentally a list, where each column of the data frame is a component of the list, because each column can have a different type of data. A data frame differs from a list because each column of a data frame must have the same length (whereas each component of a list can have a different length). A data frame is like a well-behaved list.

Reading Data from External Files

Data normally comes in the form of an external file: a spreadsheet, a “rectangular” text file (one case/observation per line), or a database. There are packages that provide functions for reading data from spreadsheets and databases and base R has several flexible functions for reading data from text files.

The readLines() function reads a text file into a character vector, with one value per line. This is useful for processing data that is not in a rectangular format (see the second half of the course). Notice in the result below that each row of the data file is a single character value; individual values have not been separated.

The scan() function reads a text file and can identify individual values within each row and can interpret numeric values. By default the value separator is white space and the result is a numeric vector. The scan() function has arguments that allow it to read character values and other types of data.

The read.table() function reads a text file in rectangular form and produces a data frame. By default, values that are separated by white space are split into different columns in the data frame.
