Use {} to form compound expressions. The value of the compound expression is the outcome of the last expression.

Loop

A loop expression allows us to express a repetitive calculation.

Other Loop Expressions

In addition to for loops, R has a while loop and a repeat loop. A while loop has the form shown below. Whereas a for loop will repeat for a fixed number of times, a while loop repeats until the condition is FALSE.

A naive repeat loop will repeat expr forever (an “infinite loop”). In practice, expr will contain a conditional expression that includes a special break expression, which halts the loop. So the typical repeat loop form is actually the one shown below (which will repeat until condition is TRUE).

Logical Conditions

The condition for both conditional expressions and while loops is a logical value, but it must be exactly one logical value (and not NA).

When we combine logical values, we have the choice of two sets of operators: & and | or && and ||. The former are vectorised operators that are to be used when combining vectors of logical values and they will produce a logical vector as the result. The latter are single-value operators that are to be used when combining single logical values and they will produce a single logical value as the result.

Furthermore, && and || are evaluated left-to-right and evaluation will terminate as soon as an answer is found (i.e., if the left-hand side of && is FALSE or the left-hand side of || is TRUE).

The ifelse() Function

The ifelse() function provides a short cut for a simple combination of loops and conditional expressions like this. The first argument to ifelse() is a vector of logical values, the second argument is a value to return for TRUE values in the first argument, and the third argument is a value to return for FALSE values in the first argument.

Function

Functions

A function expression is of the following general form: arg1 and arg2 are the names of function arguments, and expr is the body of the function, which typically involves arg1 and arg2 somehow. Arguments may have a default value, like arg2 below.

Scope

Symbols that are used within the body of a function can be either local or global. A local symbol is either an argument to the function or a symbol that has a value assigned to it within the body of the function. All other symbols are global.

Use local variables unless there is a really good reason not to and you really know what you are doing.

The Ellipsis Argument

It is possible to have ... (ellipsis) as one of the arguments in a function definition. This allows the function to be called with any number of arguments. For example, the c() function has only one argument, which is an ellipsis. This means that c() can concatenate any number of arguments.
