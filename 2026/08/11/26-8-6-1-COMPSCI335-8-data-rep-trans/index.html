DB

Generate the code.

Run the code to create the database.

Then a folder called ./Migrations and file MyDatabase.sqlite shall be created. Note that we don’t need to copy this file because the program runs in a service container.

Data Repository

The data repository provides the interface that specifies the operations on the data as well as the implementation of the interface.

Under the ./Data folder, create IWebAPIRepo.cs and DBWebAPIRepo.cs.

Passing an object of a class(WebAPIDBContext) to another class(DBWebAPIRepo) through the constructor is called dependency injection.

_dbContext.Customers.Add(customer) adds the customer object to the Customer table. The system stores the information of the added object in an EntityEntry object.

The program is running in a service container. The connection opening and closing is managed automatically.

We’ll need to register the implementation of IWebAPIRepo with the service container using Service.AddScoped. This tells the service container to use DBWebAPIRepo as a implementation of IWebAPIRepo if a program wants to use a IWebAPIRepo object.

Data Transfer Object(DTO)

The data in database might contain some sensitive information that we don’t want client to access. So we create new classes for transferring information between clients and the system. The object is called data transfer object(DTO).

Define two classes in ./Dtos:

  • CustomerInputDto.cs: carry info from client to system.
  • CustomerOutDto.cs: transfer info from system to client.

For privacy reason, we don’t want to pass Email to the client.

CustomerInputDto holds the info entered by the client. Id should be generated by the system, so DTO won’t contain. FirstName and LastName is required to be not null nor empty nor space only in the input. Use [Required] to let the compiler generate code to check whether the requirements is provided.

Controller

Controller class contains the code that handle the requests in a way that is specific to our application.

The controller code stores in ./Controller. Right click the folder and click Add. Then select Controller rather than Class. Then choose MVC Controller - Empty.

Annotation ApiController tells the system that this class contains the code for handling the HTTP request. This allows the MapControllers method in Program.cs to locate the code for controllers.

Route("webapi") tells the system the HTTP path to the methods in this class. For example http://localhost:8080/webapi.

The controller need to retreive/store data to the Customer table, i.e. a reference to the data. This is done by dependency injection. The parameter type is IWebAPIRepo.

Implementing the Methods

Implement GetCustomers, GetCustomer, AddCustomer in CustomersController and use HTTP requests to access them.

A Uniform Resource Identifier (URI) is an identifier of a specific resource. /webapi/GetCustomers. A Uniform Resource Locator (URL) is a special type of identifier that also tells you how to access it. https://localhost:8080/webapi/GetCustomers.

verb URI methods
GET /webapi/GetCustomers/ GetCustomers
GET /webapi/GetCustomer/{id}/ GetCustomer
POST /webapi/AddCustomer/ AddCustomer

GetCustomers

Annotation [HttpGet("GetCustomers")] indicates the method is called by using GET method/verb of HTTP. The relative path is GetCustomers. The URL to call this method is http://localhost:8080/webapi/GetCustomers.

The method Ok(c) sends a response back to the client with status code 200 OK. The system automatically converts c into JSON format.

GetCustomer

AddCustomer

By convention, a method invoked by http POST should return the record that has been successfully created on the server.

Object cocarries the information of the newly inserted customer. CreatedAtAction is the method for generating the response to an HTTP POST method call. By convention, in the response to the POST method of an HTTP call, the location header should include the link to the API’s method that allows the newly inserted customer to be retrieved. In this example, the method for retrieving an individual customer is GetCustomer. nameof(GetCustomer) generates the path to method GetCustomer. When calling method GetCustomer, we need to provide the Id of the customer that we want to retrieve. new { id = co.Id } generates Id. If successful, the response code is 201 instead of 200.

Register the Swagger package in the service container, then launch it in developmemnt environment. The lambda expression tells Swagger to conform to C# 8.0 and later’s nullable reference types.

Steps in Developing Web APIs

  • Define the classes that represent the data objects in the database
  • Define the DBContext class for connecting to the DB and for representing tables in the DB
  • Register the DBContext class with the service container through Program.cs
  • Set the connection string to DB in appsettings.json
  • Use Entity Framework to generate DB
  • Define the interface that specifies the operations on the data in the tables
  • Implement the interface
  • Register the interface and the implementation of the interface with the service container through Program.cs
  • Define the classes of the DTO
  • Implement the controller
