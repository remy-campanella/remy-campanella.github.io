Return a File

When returning a file, the server needs to set the Content-Type response header to indicate the type of file of being returned. This allows the browser to render the file correctly.

Type Content Type
image(PNG) image/png
text text/plain; charset=UTF-8
HTML text/html; charset=UTF-8
PDF application/pdf

The Files folder contains the file that availble on the server.

Create a controller called FileController.
