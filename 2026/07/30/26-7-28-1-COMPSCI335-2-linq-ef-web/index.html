If there is no objects satisfies, it returns an empty sequence.

Select

Select can be used to project (i.e., select) an element’s field.

Then we can get all Email fields from all customers.

Implicit Type and Anonymous Class

Declarea variable/method with implicit type using var.

The compiler will derive a actual type to it.

Anonymous class is a class without a name. Anonymous classes only have public read-only methods.

Anonymous class can be used to hold intermediate results. We’re not going to store it into the database, therefore we don’t need to declare a class to store this.

From above, customer is a sequence of Customer. Apart from extracting the fields, now we can select more than one property.

The type of customers.Select is hard to infer while coding. So we use a variable with implicit type to hold it.

Ordering Operators

Ordering operators are used to order the records in a sequence.

The delegate specify the LastName as the sorting key.

The ordering operations can be used continously(in certain cases.). ThenBy allows setting the secondary key.

ThenBy cannot be used individually. This will cause a compile-time error.

OrderBy cannot be used repeatedly. This causes logical errors and the sorting result is determined by the last Orderby.

Object Relational Mapping

Object rational mapping is to map data in SQL databases to objects in programming language and to write quries to against SQL database using statements of programming language.

Object Relational Mapper

An ORM is a library that automatically converts data stored in relational databases tables into objects used in application programs and vice versa.

Through ORM, the data in database is transferred to sequence of objects, which can operate them using methods.

Entity Framework Core(EF Core)

Entity framework is an ORM. It’s a Microsoft data access platform, open source software and cross platform.

Code First Approach

We’ll develop application classes that will be mapped to records in the database first.

We develop a class that is derived from DbContext of EF Core.

Thhen we use tools to ask EF to generate the DB tables that are used to store the objects of the application classes.

classes --> EF --> database

Database First Approach

If the databases already exists, we can use tools to generate the application classes that represent the data in the databases.

Packages

Install the tool.

Install the packages. Packages should be added individually for every project that uses Entity Framework.

Data Models

First design the classes that represent the data. A class can be regarded as the definition of table in a DB. A instance of class can be regarded as a row/record in a table.

Create a class Customer.cs in the Model folder.

The mark ? after string means this property can be assigned as null, not the default value of the type, to handle some empty value while reading.

In order to use annotation, we need to use package System.ComponentModel.DataAnnotaions. The DB has a column called primary key, we set Id as primary key.

DbContext Class

DbContext class is under the namespace Microsoft.EntityFrameworkCore. The derived class represents the DB. We interact with DB though methods of this class.

The DbContext includes a DbSet<TEntity> property for each table, representing the set of records stored in the table.

In the derived class, we override OnConfiguring to tell EF how to connect to DB.

Generate the Code for Creating the Database

Now the folder ./Migrations will have some code for generating the database. And SQLite file MyDatabase.sqlite will be created in ./. When the binary executable execute, it will try to access the file we’ve shown in "Data Source=MyDatabase.sqlite".

The DB needs to be in the same folder of the program code.

  • Select the DB.
  • Select “Advance(高级)”(or right click and select “Properties(属性)” and look to “Advance”).
  • Set “Copy to Output Directory(复制到输出目录)” to “Copy always(始终复制)”.

Now the database file will be copied to ./bin.

Manipulating Data in the Database

Add

This created some instance of customer in a list.

To add these records, we should connect to database.

  • The using statement releases the resource when the code execution was finished.
  • dbContext.Customers represents all records in table Customers in the DB.
  • DbSet.Add method inserts records to the table.
  • DbContext.SaveChanges method saves the changes had been made.

Get

  • Use Where method of LINQ to filter the records.
  • Use a loop to display all the records being selected.
  • The database has only been read. We don’t need SaveChanges.

Delete

  • Use FirstOrDefault to find the record(s).
  • Check whether the record(s) is found(!= null).

Web API

Web API Doc

Client/Server Architecture

flowchart LR

client --request--> server <--> database
server --response--> client

API

API defines a set of operation that the clients can use to interact with the server.

RESTful API

REST is representational state transfer. When a client request is made via a RESTful API, the API transfers the representation of the state of the resource requested by the client to the client(i.e. the current state).

JSON is one of the most popular formats to deliver representation.

Web API is an API which can be accessed using HTTP protocol. It is cross-platform as long as using HTTP. It provides good flexibility as its easy intergrations. It is widely used in service-oriented architecture.

HTTP

HTTP Request Message Format

  • a request line.
  • zero/several headers.
  • an empty line.
  • a message body(optional).

GET/POST: HTTP verbs.

HTTP Response Message Format

  • A status line.
  • Zero/multiple headers.
  • An empty line.
  • A message body(optional)
