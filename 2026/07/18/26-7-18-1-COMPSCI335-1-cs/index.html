Development Using VS

Initialise a project:

  • console: this is a console application.
  • --use-project-main: tell the system to generate a Main method.

The project will be initiallised in ./ex1. Click the .csproj file and choose Visual Studio to open it.

Main Components of a C# Program

  • namespace declaration
  • class declaration
  • class methods
  • fields and properties
  • main method(entry points)

C# is similar to Java. This course only touches C#-unique features.(Are you sure?)

VS will ask you wether to save a .sln file. You can click this solution file to open your project.

Class, Method and Field Variables

Add a class:

  • Right click project name in browser.
  • Choose “Add”.
  • Choose “Class”.
  • Choose “C# Class”(or other kinds) and edit the name.
  • Enter or click “add”.

Create Class Instance

Property

C# provides a programming construct called property that combines the field variables and the methods for accessing them together.

Now the property LastName can be accessed and assigned directly.

Read-Only/Write-Only Property

The property only got a getter, it can be accessed, but cannot be modified. So it is read-only.

If the property only has a setter, then it is write-only.

Define a backing field for holding the value of property. Property itself won’t store the value!

In fact, if you only write a property, the compiler will automatically add a backing field. However, we’d better write it by ourselves because the setter needs validation.
