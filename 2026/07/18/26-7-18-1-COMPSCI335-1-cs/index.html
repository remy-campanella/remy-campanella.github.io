Create Class Instance

Property

C# provides a programming construct called property that combines the field variables and the methods for accessing them together.

Now the property LastName can be accessed and assigned directly.

Read-Only/Write-Only Property

The property only got a getter, it can be accessed, but cannot be modified. So it is read-only.

If the property only has a setter, then it is write-only.

Define a backing field for holding the value of property. Property itself won’t store the value!

In fact, if you only write a property, the compiler will automatically add a backing field. However, we’d better write it by ourselves because the setter needs validation.

Inheritance

A child class can inherit the class properties/variables and methods from its parent class.

Interface

A interface define some methods, no implementation.

Use a concrete class to define a interface.

In C#, the name of an interface should starts with I.

All classes inherited the interface must implement all methods the interface has.

Operations on Data Objects

By convention, we place all classes that manipulate data objects in a folder Data. The folders includes interface definitions, the class that implememt the interfaces and classes that carry out operations on the data objects defined in Model folder.

Delegate

Delegate is a data type that points to a function/method.

LINQ(Language Intergrated Query)

Data are stored in many formats, such as rational DB, XML, etc. Traditionally, we use SQL to access them. Microsoft has intergrated this access with programming through LINQ. In LINQ, record in data stores are represented as sequence of objects.

The LINQ library actually provides some methods.

Example

There is a data store with a collection of Customer type objects.

An interface is defined that allows us to

  • retrieve all the Customer objects from the data store. GetAllCustomer
  • retrieve the Customer object with a given ID. GetCustomerByID

FirstOrDefault(<delegate>)

Returns the first element that satisfy the condition in a sequence, or a default value (can be null) if no element is found.

The parameter is a delegate that checks whether the condition is satisfied.
