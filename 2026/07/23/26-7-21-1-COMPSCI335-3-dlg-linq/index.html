Delegate

Delegate is a data type that points to a function/method.

Declare a Delegate

This means the function pointed by a Foo1 type variable must have the same signature as Foo1.

  • The function returns an int type value.
  • The function has two int type parameters.

LINQ(Language Intergrated Query)

Data are stored in many formats, such as rational DB, XML, etc. Traditionally, we use SQL to access them. Microsoft has intergrated this access with programming through LINQ. In LINQ, record in data stores are represented as sequence of objects.

The LINQ library actually provides some methods.

Example

There is a data store with a collection of Customer type objects.

An interface is defined that allows us to

  • retrieve all the Customer objects from the data store. GetAllCustomer
  • retrieve the Customer object with a given ID. GetCustomerByID

FirstOrDefault(<delegate>)

Returns the first element that satisfy the condition in a sequence, or a default value (can be null) if no element is found.

The parameter is a delegate that checks whetherthe condition is satisfied.
